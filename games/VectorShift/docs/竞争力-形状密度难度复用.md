## 0. 一句话结论

品类头部并不靠「同一个方格 + 点一下滑出去」赢到 50M–1 亿下载。**轮廓异形、密度节奏、管状美观、交错深度、素材复用**才是商店截图与中后期留存的差异面。相位（蓝旋转 / 金固定）是 VS 的 USP，必须挂在这些变奏之上，而不是替代它们。

## 1. 换形状（异形轮廓）

### 1.1 竞品怎么做

| 形态 | 证据 | 说明 |
|---|---|---|
| 心形 | 【截图可见】`arrow_out_ss1` LEVEL 32：米色心形剪影，蛇从心形边缘滑出虚空 | 剪影本身是可营销素材 |
| 躯干/蘑菇形 | 【截图可见】`arrow_out_ss2` LEVEL 27：不规则浅灰剪影 + 高密折线 | 非几何正多边形也能读 |
| 超大 S 蛇剪影 | 【截图可见】`snake_arrow_ss1`：小蛇拼成「大蛇」轮廓（头+信子） | **形状即主题包装** |
| 椭圆/卵形 | 【截图可见】`cn_ss1` Level 23 Geometric Flow：圆角卵形剪影，外圈虚空 | 几何主题包命名 |
| 方密盘 | 【截图可见】`snake_arrows_ios_ss2`：仍用矩形，但近满填 | 异形不是唯一手段，但是截图杀器 |

**【推断】** 雪花 / 树 / 字母 / 节日物体：商店描述与竞品流程对照文档多次提到「心/树/雪花」异形棋盘（Arrow Out 系）；字母与节日剪影是同管线换 mask 即可，未见反证。

### 1.2 可玩区域 vs 装饰

- **可玩区域**：mask 内格子；有地板色/点阵；蛇只能占 mask。  
- **装饰 / 虚空**：mask 外不画地板（或透明），**【截图可见】** 滑出越过剪影边界即离场（`arrow_out_ss1` 绿色箭头半截伸出心形）。  
- **底板点阵**：部分竞品在虚空仍保留淡点（Arrow Out 米色底）——装饰，不参与碰撞。

### 1.3 商店截图素材价值

异形剪影在 5 张商店图里立刻回答「这不是又一个方块消消」：

1. 教学方盘（规则清楚）  
2. 心形 / 节日（情绪与分享）  
3. 高密交错（「好难但好看」）  
4. 主题包封面（Geometric Flow / 蛇形超轮廓）  
5. 结算 / Daily streak（运营层，非形状）

**【VS 决策】** 中期起 ≥40% 关卡使用非 square mask；教学前 8 关保留方盘降低认知负荷。

### 1.4 VS 出界规则（P0 已定，全栈一致）

> **occupied + 空可玩格 = 剪影；出口射线沿朝向前进，一旦下一步落到「不可玩 = 虚空」即视为滑出成功（clear）。**  
> 不可玩格根本不存在地板，不能被站、不能被穿行计阻挡。  
> 与 Arrow Out 异形盘一致；`validateLevel` / solver / UI 预览共用此规则。  
> 环/甜甜圈：内洞也是虚空 → 朝内洞滑出同样算 clear（P0 接受；P1 可加「仅外轮廓可出」开关）。

Schema：

```json
{
  "size": 7,
  "shape": "heart",
  "mask": [[x,y], ...],
  "arrows": [{ "id": 0, "color": "blue", "d": 1, "cells": [[...]] }]
}
```

`shape` 为命名 id（审计/主题包）；`mask` 为权威可玩集。缺省 `mask` ⇒ 满方盘（兼容旧关）。

## 2. 换密集程度（节奏表）

### 2.1 竞品节奏（观察）

| 带 | 观感 | 证据 |
|---|---|---|
| 早期稀疏 | 少量短蛇、大量空地板 | 【推断】教学关普遍如此；VS 现 L1 ≈16% |
| 中期密 | 剪影内大部分被占 | 【截图可见】`cn_ss1` / `arrow_out_ss2` 约 80%+ |
| 后期极密 / 异形密 | 近满填 + 异形边缘出口竞争 | 【截图可见】`snake_arrow_ss1`、`snake_arrows_ios_ss2` ≈90%+ |

### 2.2 VS 建议关卡带（相对 **mask 格数** 的 fill%）

| 关卡带 | size 约 | 形状策略 | 目标 fill（body/mask） | 教学意图 |
|---|---|---|---|---|
| L1–3 | 5 | square | 15–35% | 点滑、阻挡顺序 |
| L4–8 | 5–6 | square | 40–55% | 相位引入 |
| L9–14 | 6–7 | 引入 plus/diamond | 45–60% sparse→medium | 「这盘不是方的」 |
| L15–22 | 6–7 | heart / letter | 60–72% | 异形 + 相位 |
| L23–38 | 7 | ring / heart / T | 68–78% | 出口竞争 |
| L39–52 | 7–8 | 异形密 + 方密交替 | ≥70%（dense 带） | 多相位 + 交错 |

**【VS 决策】** fill 一律按 `bodyCells / maskCells` 计量；旧「相对 size²」在异形下会虚高/虚低，审计 CSV 同步改。

## 3. 形状与美观

### 3.1 竞品美观要素

| 要素 | 证据 | VS 现状 / 缺口 |
|---|---|---|
| 管状高光 | 【截图可见】iOS 蛇箭头：粗管 + 白高光 + 眼睛 | VS 已有 chunky stroke + highlight（V0.6-dense） |
| 眼睛 / 箭头头 | 【截图可见】蛇系有眼睛；Arrow Out 系是尖箭头头 | VS 用集成三角箭头头；眼睛为 P1 |
| 配色 | 多色糖果管 vs 单色海军线 | VS：蓝相/金相两族多色相 |
| 背景主题 | 白底 / 米色点阵 / 章节名 | VS：单主题；P1 主题包换 `--board` / 虚空底 |

### 3.2 相位 USP 如何不破坏美观

- **保留**：蓝 = 相位体；金 = 锚点。颜色语义稳定，玩家扫一眼知道谁会转。  
- **旋转动画**：身体绕头 CW 90°，短 easing；不要换成「瞬移换皮」。  
- **异形上的约束**：相位后所有蓝格必须仍 ∈ mask（生成器双相位校验），避免「转到虚空」毁美观与信任。  
- **预览**：畅通绿 / 阻挡红仍沿可玩格画到虚空边界，尖端可探出一格暗示「出口在剪影外」。

## 4. 难度增加（不靠单纯加格子）

### 4.1 竞品难度来源【截图可见 + 推断】

1. **交错深度**：折线互相咬合（指纹感）  
2. **出口竞争**：多条蛇抢同一边缘出口通道  
3. **误触面**：生命心 + 点错弹回（Arrow Out / 蛇系 HUD）——VS 暂无生命，靠撤销  
4. **视觉噪声**：近满填提高读图成本  

相位强制次数是 VS **独有**难度轴，竞品无对等物。

### 4.2 可度量指标（生成器 / 审计应输出）

| 指标 | 定义 | 用途 |
|---|---|---|
| `fillRate` | bodyCells / maskCells | 密度带 |
| `maskCells` | \|mask\| | 形状规模 |
| `blockingArrows` | 至少一相位射线命中别人的蛇数 | 交错 |
| `initialChoices` | 开局可滑出数 | 入口宽度 |
| `minToggles` / `phaseRequired` | 最短解相位次数 | USP 难度 |
| `minSteps` | 最短动作数 | 长度 |
| `exploredStates` | BFS 状态数 | 搜索宽度 |
| `perimeterExits`（P1） | 开局朝向一步即虚空的蛇数 | 边缘出口供给 |
| `crossingPairs`（P1） | 射线互相命中的无序对数 | 出口竞争 |

难度配方建议：中后期优先抬 `blockingArrows` + `minToggles`，再抬 fill；忌只加 size。

## 5. 复用方式（避免「52 关长一样」）

| 手法 | 做法 | 成本 |
|---|---|---|
| 同轮廓换色 | 固定 mask + 重采样蓝/金与色相 | 低 |
| 镜像 / 旋转 | mask 与 arrows 同变换；相位旋转要重新校验 | 低–中 |
| 主题包 | 一组 shape id + 背景皮肤 + 教学文案 | 中 |
| 日挑战种子 | `date → seed →` 生成器参数档 | 中（已有 offline daily） |
| 皮肤 | 管状贴图 / 眼睛 / 节庆帽（不改规则） | 中 |
| 生成器参数档 | band 表：size、shape 池、fill、toggle、len | 已有 + 本轮扩 shape |

**【VS 决策】** P0：shape 模板池轮换 + density band；P1：镜像复用管线；P2：主题包与皮肤商城位。

## 7. 风险与已知极限

- 异形 + 双相位占位约束会让生成更慢；P0 允许 dense 带 soft fill 下限。  
- 环洞作出入口会改变直觉，需在教学条提示「滑向缺口也算出界」。  
- 截图素材未覆盖全部字母/雪花实机关——雪花等标【推断】。  
- 本轮不实现生命心与付费提示，避免和 Coolmath 渠道冲突。
