# G04 项目章程｜折光机关 Layer Relay

版本 1.0.0；冻结/研究访问日 2026-10-21。状态 **INDEPENDENT_REVIEW**；`ready_for_build=false`。这是准备交付，非游戏成品、非已批准施工。原创名称、规则、关卡、预算、体验指标均为 **HYPOTHESIS**，只表示本项目待检验设计，不主张已获市场验证或法律上的独创性认定。

## 玩家与需求

面向喜欢可预测机关、空间规划、撤销复盘的 16 岁以上一般解谜玩家；不做儿童启蒙、幼儿识色、儿童角色或儿童定向推广。移动触控和桌面键鼠同等支持，预期一次关卡可在短会话完成，但实际时长 **UNKNOWN**。P02 要求遵循 PEGI-12 内容指导并排除面向儿童内容（E05）；“16+目标受众”不是已经取得年龄分级。

玩家要在上下两层机关板间移动一枚光标，踩入开关改变共享位型，利用一层开而另一层关的门抵达出口，同时恢复指定终局位型。核心问题是“何时借用另一层、哪些位要留下、哪些必须复位”。棋子和机关不消除，不按箭头方向移出场景，与 G01 的移除依赖图不同。

## 渠道与资产目标

首选 P01 Coolmath：研究 thinking game 与非独家托管许可的适配，报价、采购意愿、周期 **UNKNOWN**。次选 P02 CrazyGames：Basic 玩家测试，是否进入 Full、实际流量和回款 **UNKNOWN**。只保留这两个 G04 候选渠道；P03/P04/P05/P06 仅在 11 中记录排他、SDK 或权利边界，未新增为候选。P04 禁第三方统计的约束作为以后获批适配的明确禁令，不代表本轮开发 P04 包。

希望持有原创关卡、UI、音画、规则数据和实现版权，按合同许可游戏运行；通用机制工具和数据验证器应列为保留资产。非独家许可商业化须有真实协议与净回款，网页陈列和可投表单不算验证。

## 冻结范围

- 一个 B0 主版本：20 个具名原创关卡、2 层离散网格、至多 3 个开关位、1 枚棋子、进入触发 XOR 开关、升降台、门、精确位型目标、有限步数、免费撤销/提示。
- 两个独立实验：X1 顺序信标；X2 延迟一个合法移动生效的开关。两者不叠加，不是另增游戏 ID。
- 全流程中英文本，存档、错误恢复、静音、减动效、色形双编码；无货币、体力、IAP、榜单、聊天、账号、自有后台和 V1 广告。
- 本轮仅文档、JSON、Schema、离线规格验证、审计交接和压缩包。不产生 Cocos 场景、TS 游戏逻辑、可玩构建，不安装引擎，不投稿、不发信、不签约。
