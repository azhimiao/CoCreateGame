01 / SHAPE + PATH

先有大形，再有路径。

每个剪影有识别特征、内部主脊与负空间。连续轮廓转成 mask 后，必须重新检查两相位与可解性。

候选分辨率：简单形体 12～16 格，复杂形体 16～24 格；现核心上限 12，现关卡最多 8。这里的曲线是原创造型草案，不是已验证的 mask。整盘旋转、换色不计新谜题。

02 / VISUAL LANGUAGE

圆润统一，语义稳定。

固定光源、连续圆角、柔和接触影。远看完整，中看路径，近看细节；颜色不再随主体随机跨类别。

蓝体 / 弧形转动标记固定体 / 双短条

一个材料系统

同一管宽比例、头身比例、转弯半径与光源。明暗表达体积，不用粗黑边与方折白线勾每一层。

两套稳定语义

蓝色始终代表可旋转，金色始终固定。关闭颜色后，头后标记仍保留类别区别。

三个观看尺度

剪影形成整体，长中短路径形成组织，眼睛与高光只做细节。先看形，再看路，最后看装饰。

此处为 SVG 材质草图；最终管身需在真实密盘检验光照连续性、邻体区分和手机像素尺寸，不能仅凭这两根样条验收美术。

03 / INPUT + FEEL

按下有回应，动作有方向。

试三个动作，或拖动进度查看中间帧。滑出用沿路径移动的窗口；相位展示实际 90° 插值。

选择动作，观察完整过程0%

说明模型：没有声音或震动，不做游戏碰撞判定；时间仅为样板设定，不是实体设备实测。

≤50ms

先确认碰到了谁

输入首帧响应的 P95 目标。按下确认对象，松开一次提交；滑动或捏合取消点击。

240–620ms

头领路，尾跟随

沿尾到头的原路径推进，再从出口离场。身体不作为刚体横扫邻体。其它主体可连续操作。

140–200ms

受阻也要讲清原因

沿前进方向微推回位，只点亮最近阻挡点。命中失败、被挡与切换中必须分得清。

220–300ms

两种相位，可逆旋转

0→1 为 +90°，1→0 为 −90°，以头为轴。固定体不动；实际游戏还要验证瞬态穿越的投影表达。

04 / DIFFICULTY

密集是观感，有后果才是选择。

路径查找可以有乐趣，但不能冒充顺序决策。先用最小反例证明新规则改变了什么。

现有规则 · 已审计

移除只会让局面更宽松

合法移除不会关闭任何既有通路。现在所有关卡都能按“能出就点，卡住切相位”完成，且切换次数最优。

继电出口 · HYPOTHESIS

移除可以改变共享条件

A 只能从门离开；继电体 R 离开后关门。顺序开始有后果。先做真实几何关、好坏分支回放和四关教学，验证后决定是否采用。
