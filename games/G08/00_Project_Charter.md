# G08｜群体答案问答：候选章程

访问/编写日：2026-10-21。批次：P1。项目状态：EVIDENCE_COLLECTED；档案状态：SPEC_NOT_COMPLETE；ready_for_build=false。本文件是准备阶段研究结论，不是批准施工的产品定义。

## 目标玩家与待解决问题

HYPOTHESIS：面向喜欢猜测某个明确群体如何回答日常问题、愿意接受短局反馈的休闲玩家；先验证单一语言/地区，不把英语群体答案自动翻译成全球共识。真实地域、输入习惯与文化差异UNKNOWN。

研究能否以自有或明确授权的调查语料形成可信、可维护的原创问答IP。仅P06为本项目候选发行渠道；Family Feud/Fremantle、Arkadium、Microsoft都是对标/来源背景，不增加平台ID、合作方目标或投稿任务。

## 原创方向与范围

HYPOTHESIS：阅读原创情境问题及样本标签 → 输入一个答案 → 规范化匹配 → 对照该样本实际频次揭示 → 得到有来源的分数解释 → 下一题/回顾。题库、样本量、计时、得分、晋级和对手模式均未定。

先解决语料出处、授权和答案匹配，不把普通知识题的唯一正确答案当作群体回答。暂无真人联网对战需求；若以后使用机器人或离线对手必须明确告知，不能把页面营销所称实时全球对手当已核实网络架构。

HYPOTHESIS G08-H1：明确显示答案来自哪个样本，并允许围绕预测信心或不同群体差异展开决策，比宣称不明来源的“全球最常见答案”更可理解且更值得重玩。

- **B0 基线**：同一合法调查题，展示明确样本标签与按该样本频次揭示；不加信心押分或分组比较。标签是诚实底线，不能用假来源作实验。
- **V1 信心选择**：只增加提交前的低/高信心选择；额外得失规则待审，不改答案与样本频次。
- **V2 群体比较**：只在有真实且获准使用的分组样本时允许预测哪组更常回答某项；不加信心选择，不伪造群体差异。

上述B0/V1/V2均为自拟实验方案，未开发、未测得结果，也未证明独创性；参考作品只用于机制比较，不复用其专有表达。

## 首要成本与技术风险

大小写/全半角、拼写与同义词、Unicode/IME输入、计时边界和重复提交可能造成错误判罚；模糊匹配误接纳需与误拒分别计量。语料版本/样本来源/聚合权利需要可追溯，AI可协助草拟问题但不能伪造调查频次或把生成排名当真实样本。

原创问题文本、经许可匿名聚合频次、匹配词表、原创界面角色/题目插图、字体与提示音。调查使用许可需覆盖商业使用、编辑、衍生与发行商转授权；受访者同意/保存边界待落实。本轮不招募、不收集个人数据、不发问卷或外联。
