# 组合成本、净回款与止损

本轮不存在新作营收、发行报价、买量预算、RPM或CPI测量。除有来源的公开结算说明外，金额和成功率均UNKNOWN。本文件定义后续记账和敏感性计算，不能当作投资回报承诺。

## 记账口径

组合净贡献 = 实际收到的净授权款 + 实际收到的净分成款 − 全部研究/失败原型/研发/AI调用/素材/测试/获客/法务/税费/维护成本。

ROI = 组合净贡献 / 全部投入。成本为0时ROI未定义，收入未知时不得写0利润。应计收入、后台预估、已开票和已收款分四列；同一用户广告收入经平台和发行商扣除后不得重复计算。

## 预算输入

| 输入 | 本轮取值 | 后续证明 |
|---|---|---|
| 每项目人时及费率 | UNKNOWN | 工时单与确定的机会成本口径 |
| AI/素材/设备/法务现金成本 | UNKNOWN | 账单、发票、分摊规则 |
| 授权费、广告分成净额 | UNKNOWN | 协议、后台和实际汇款对账 |
| CPI/留存/LTV | UNKNOWN | 同国家/版本/时间窗口的真实测试 |
| 采购/审核成功率 | UNKNOWN | 样本量和所有失败项目，不拿热榜推导 |
| 维护及下架成本 | UNKNOWN | 月份、支持工时、固定及变动费用 |

在正式开发前先由用户定义一次实验的现金/工时上限；不能默认无限迭代。每阶段花费达到上限且证据无改善时停止增量投入，保留文档和通用工具。

## 敏感性与盈亏点

若组合总成本为C、已收到其他净回款为R、单次非独家许可实际净额为L>0，则补足盈亏的许可次数为 `ceil(max(C−R,0)/L)`。L未知时只输出表达式，不给“预计售出N份”。

Playgama公开分发函数（来源C20/S28）可写为：合作站点月净收入N，开发者份额 `0.7*min(N,1000)+0.8*min(max(N−1000,0),2000)+0.9*max(N−3000,0)`；站内及iframe伙伴流为`0.5*N`。两种N先按收入流归类，禁止同笔收入重复套用。这里的N是合同定义净收入，不是玩家消费或广告主总花费；税费/扣除、实际流量、支付资格和到账仍UNKNOWN。

敏感性优先变化：可核实曝光→启动→有效游玩转化、净结算基数、维护人时、失败比例、到账延迟。每项先建可测数据，禁止补“行业通常值”。

## 实验闸与退出

市场研究能检验入口是否公开、同类是否拥挤、规则是否可定义，不能检验真人喜好或采购价格。后续只有在用户批准的最小切片中收集操作误解和复玩证据，才决定美术和内容扩展。项目的具体体验停止条件见各 `12_Falsifiability.md`；商业停止条件是渠道权利不可兼容、预期修改义务超预算、无法取得必要指标或净回款长期低于可观测维护成本。

公开依据：[Playgama结算](https://wiki.playgama.com/playgama/faq/payments-and-statistics.md)、[CrazyGames结算](https://docs.crazygames.com/payouts/)、[Poki结算](https://developers.poki.com/guide/payouts-billing)。它们只说明公开机制；本项目实际利润未验证。
