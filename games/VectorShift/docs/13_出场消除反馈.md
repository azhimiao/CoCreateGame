# 出场与清除反馈修订

2026-10-22。依据用户提供的出口截断截图修订；本次只调整 Vector Shift 的出场呈现与完成确认。

## 问题与实施

原动画沿正确路径爬行，但运动像素直接到达 Canvas 的硬边，身体在屏幕边缘形成平直切口；“又解开了一点”在动画刚开始时就触发，无法确认何时真正清除。

- 静止棋盘和运动主体分别绘制。运动层在四个屏幕出口渐隐，宽度为半个显示格距、最多28 CSS px；不缩小棋盘，不改变点选坐标，也不让静止蛇贴边褪色。
- 爬行尾部留三枚同色细小光点，沿刚腾空的路径跟随；完整离场后出口有280ms的散点收尾。
- 启动时显示“畅通，出发！”，真正提交清除后显示“漂亮，清掉一条！”，多个动作同帧结束则显示合计。计数/进度与此同步；成功提示有340ms的轻微弹出。
- 声音开启时，启动短音和完成双音分开；开启触感且浏览器支持时，完成有独立短振。默认开关偏好保持原设置。
- 系统或游戏内“减少动态”跳过出场/散点/提示弹出，立即完成合法动作；切换时取消装饰动画。
- 所有渐隐均为绘制效果。占位、交叉路径预约和存档提交仍保留到完整动作结束；不会因为尾部已经很淡就提前允许穿越。

## 可复验记录

`tests/clear-feedback.cjs` 在390×844和844×390，逐一真实触摸上/右/下/左四向夹具，受控时钟定位尾部越界帧，直接读取实际Canvas像素。由边缘向内四点alpha分别约3、64、130、191（横屏约3、65、127、189），验证连续渐隐；同时核对离场中占位、完成后计数/提示以及减少动态清空。
