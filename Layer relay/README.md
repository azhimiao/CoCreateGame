# Layer Relay · 折光机关

Godot 4 等距 2.5D 双层解谜项目，现有 **01–50 共 50 关**。01–30 为分机制课程，31–40 为复合机制递进，41–50 为大型分支挑战。旧四个示例仅保留为隔离测试样本；原研究与施工档案不随原型改写。

## 运行

在 Godot 中打开本目录的 `project.godot`，按 F6/F5 运行主场景；也可从仓库根目录执行：

```powershell
godot --path "Layer relay"
```

仅使用 Godot 内置节点及程序绘图，运行游戏不需要 Python 或外部素材。

所有 50 关按顺序解锁，31/41 不再是自由进入的验证关。选关每行六关，可上下滚动，仍保留 66 个空间坐标，51–66 尚未开放。41–50 标为挑战，步数余量约为最佳解的 1/6；前面课程余量约为 1/2。完整逐关表见 `CAMPAIGN.md`。

周期性致死格已从关卡、规则、引导和渲染中删除。步数耗尽及原有机关错误仍会失败，保留动作结束后的失败演出和重开/选关流程。

## 图案识别

所有格面文字均已移除，包含“翻位”“延迟”、位字母、门条件、升降、终点及道具短标签。格子与图文规则共用同一套程序绘图：

- 圆、菱形、三角分别表示三个共享位，目标卡使用 ○、◇、△ 对应。
- 翻位格显示通道图案；多个图案表示联动，小钟表示下一次有效动作后结算。
- 位门前的实心通道图案要求该位点亮，空心要求熄灭；钥匙门使用钥匙孔。
- 双环表示升降，箭头表示逆流，轨道箭头表示移动方向；钥匙、锚片与出口保留各自图案。
- 悬浮信标用圆点数量表示先后次序；达标勾号仍在格子中央圆形区域，颜色与勾号保留渐变。

气泡引导和规则说明同步使用图案词汇。首次进入第一关介绍七个界面部分；新机制首次出现时框选对应机关，可前后翻页，阅读时暂停计时与操作。41 关新增两步路线规划说明。同一关未读引导使用连续页码，气泡限制在可见窗口内，长文内部滚动。

## 操作与评分

- 方向键 / WASD 或点击合法相邻格：跳跃。
- X / 空格或点击脚下升降台：切层。
- Z / 退格：撤销，恢复主角所在层、机关、道具及主视图。
- R：重新开始；H：提示；Enter / Esc：暂停与恢复。
- 点击右上缩略图：动画交换两层视图，只查看、不消耗步数。
- 失败后 R / Enter 重开，Esc 选关。

三星为三个独立条件：完成通关、在目标时间内完成、在最佳步数内完成。提示不直接扣星，撤销不倒退计时。生成、主角入场、引导、暂停、规则及庆祝不计时。最后一步满足全部目标仍可通关。

大地图提示采用参考路线缓存与 A* 搜索。偏离参考路线后在后台重新计算，界面保持响应；若玩家移动、重开或换关，旧结果不覆盖新局面。搜索得到的后续路线会缓存。复杂局面可能需要数秒计算。

## 视觉与流程

保留胶囊四向抛物线翻转、落地回弹、带前沿遮挡的椭圆传送门、主图与缩略图缩放交换、逐格扩散生成和主角平滑入场。机关状态与道具变化始终在角色及平台移动结束后演出；平台与直立胶囊在边界分段绕回。

大型地图使用紧凑缩略图，为主棋盘增加空间；图案随地块尺寸缩放。目标卡、缩略图、道具栏在 1360×860 和 1080×720 下均做遮挡检查。通关后保留终点高亮、彩纸和下一关/重玩/选关。

## 存档兼容

本地存档为 `user://layer_relay.cfg`。从旧 32 关版本迁移时保留 01–31 的星级与有效进度，备份为 `layer_relay_before_expansion.cfg`；旧 41 验证关成绩及局面不会映射到新挑战关。较早四示例版本仍备份到 `layer_relay_before_campaign.cfg`，独立开始新战役。教学更新会重开一次图案说明，保留战役星级。选关重置需要再次确认。

## 数据与验证

- `data/campaign.json`：固定的 50 关数据，含目标、最佳解、步数和时间目标，不在运行时随机生成。
- `tools/build_campaign.py`：作者工具与独立 Python BFS，生成数据前验证所有最短解。
- `tools/late_campaign.py`：32–50 的确定性分支布局，固定种子、资源支路、串行锁室与摆渡。
- `scripts/game_rules.gd`：纯规则；`hint_search.gd`：提示；`board_view.gd`：绘图与时序；`main.gd`：流程及存档。

从仓库根目录运行：

```powershell
python -X utf8 "Layer relay/tools/build_campaign.py"
godot --headless --path "Layer relay" --script res://tests/test_campaign.gd
godot --headless --path "Layer relay" --script res://tests/test_hint_search.gd
```

共十组测试：campaign、hint_search、rules、board_view、ui、frontend、completion、feedback、transitions、tutorial。Python 检查 50 关精确最短步数，Godot 重放全部 50 关并独立搜索前 31 关；同时检查机制阶段、必经资源、运行时提示、三星、顺序解锁、失败重试、撤销、旧存档迁移和全部 50 关双层/双尺寸遮挡。提示测试覆盖大图偏离路线、剩余步数、未缓存最优路线、后台暂停响应及过期结果丢弃。

实际引擎录帧命令：`godot --path "Layer relay" --script res://tests/capture_campaign.gd`，输出 `runtime/campaign-review/`，测试与录帧均使用独立临时存档。难度和时间目标仍需结合实际游玩反馈调整。
