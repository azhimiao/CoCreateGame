## 1. 产品目标与当前裁决

玩家应依次感到：**整体造型有吸引力 → 局部路径读得懂 → 动手有明确反馈 → 解开结构有成就感**。不是靠大量按钮、花色或关卡编号制造完成感。

| 指标 | 本次审计结果 | 正确解释 |
| --- | --- | --- |
| 关卡数 / 网格边长 | 52 / 5～8 | 技术内容量，不代表精品关卡数量。 |
| 独立主体数 | 2～9，中位数 6 | 管子变长增加占用，不自动增加独立决策。 |
| 占用率 | 中位数 76.37%，最高 94.29% | `bodyCells / maskCells`，不是截图像素覆盖率。 |
| 最少相位切换 | 0 次：2 关；1 次：36 关；2 次：14 关 | 当前相位是 `0↔1`，不是反复同向旋转。 |
| 无前瞻策略 | 52/52 关可解，且全部达到最少切换 | 把当前相位所有能出的移除，直到没有，再切相位。 |
| 可达局面 / 合法移除边 | 2,700 / 5,065 | 不计撤销、重开；清空即终止。 |
| 合法移除后失去可解性的边 | **0** | 口径：移除前可解、移除后即使不限切相位也无解。 |
| 形状数量 | square 22；diamond 7；plus/blob 各 5；heart/ring 各 4；T 3；C 2 | 标签多不代表剪影品质高。 |
| 旋转去重 | 未发现完全相同棋盘 | 只检查整盘旋转、忽略主体 ID；未证明抽象逻辑不重复。 |

**为什么现规则很难产生顺序策略：**在相同相位下，移除只会删掉占用格，其他主体的位置和出口条件不变。原先可出的仍可出，原先被挡的可能变通。相位可不受资源限制地切回（仍会增加步数和切换统计）。因此任何合法移除都可提前做；某条解里再遇到该主体时跳过它即可。当前相位先做完所有合法移除，也不会破坏后面的解。这个性质来自规则，不是某一批关卡生成得不够随机。

结论：可以保留它做舒缓找路模式，但不能据此宣传“点错顺序会锁死”或“多步战略”。缩小目标、加生命、增加误触、拖长动画，也不算逻辑难度。

## 2. 体验原则与理论落点

下表是设计依据与可证伪预期。除明确引用的原则外，具体参数均是本项目 V1 工程目标，**不是已测得的竞品参数，也不是普适心理学定律**。

| 原则 | 本项目的具体决定 | 怎样发现决定无效 |
| --- | --- | --- |
| 从体验反推机制 | 用 MDA 的规则→运行行为→体验关系，反查“想要规划感”是否真的由状态变化产生。[原论文](https://users.cs.northwestern.edu/~hunicke/MDA.pdf) | 求解器证明简单贪心总是最优，则不能把该内容评级为策略关。 |
| 整体先于局部 | 剪影、长短节奏、连续路径形成三种观看尺度；沿用相似材质把所有主体组织为一盘。 | 缩至 96px 只剩随机色块，或只能靠标题认出轮廓，则返工造型。 |
| 难度应来自问题 | 将视觉查找、规则理解、因果推理、点击负担分别记录。 | 解法没变，只是字小、蛇细、误点多或等待更长，则难度升级失败。 |
| 控制与结果要有因果感 | 输入确认立即开始，动作方向与规则一致；成功、受阻、相位切换用不同反馈语汇。NN/g 的经典响应时间讨论支持快速可感知响应的重要性，不给出本作最佳动画时长。[原文](https://www.nngroup.com/articles/response-times-3-important-limits/) | 玩家分不清“点到了但被挡”和“根本没点到”；连续操作被全屏锁住。 |
| 触碰容错与可恢复 | 常规控件至少 44×44 CSS px；密盘不靠重叠大热区冒充可点击，提供放大及键盘等价操作。44px 对应 WCAG 增强目标尺寸说明，不能据此宣称整盘已达 AAA。[W3C](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html) | 热区命中邻蛇、指尖遮住预览、放大后仍不能稳定选择。 |
| 运动服务信息 | 相位变化说明方位，滑出说明通路；减少运动时保留状态与方向线索，关闭装饰性位移。[W3C](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html) | 关动画后玩法含义丢失，或必须忍受全屏震动才能知道受阻。 |

“观感 × 手感 × 深度”是三个独立质量门。一个维度得分高不能抵消另一个维度不合格。

## 3. 整体形状与变体语法

### 3.1 形状是先设计的容器

每个关卡先提交黑白剪影与负空间图，再放主体。禁止从随机蛇布局反向命名一个模糊的 `blob`，然后算成新形状。

形状分三层，三者必须同时登记：

1. **外轮廓**：这盘远看是什么；控制重心、宽高比、凸凹节奏。
2. **内部编排**：主体怎样形成主脊、侧翼、转折和疏密分区；同一剪影至少两种实质不同的编排。
3. **局部词汇**：直段、U 弯、S 弯、回折、短接片的比例；让长路径有可追踪的节奏。

### 3.2 首批形状家族

以下是生产设计范围，不是已经通过可解性验证的 mask。样板中的连续轮廓须先栅格化，再与两相位占用共同求解。

| 家族 | 必须保留的识别特征 | 内部编排要求 | 允许的变体 |
| --- | --- | --- | --- |
| 软矩形 | 四边稳定、圆润四角 | 一条主回折带 + 两个辅区，避免等长平行面条 | 横/竖版，主带换侧；不计全盘旋转为新题 |
| 心形 | 双肩、中央凹口、向下收尖 | 肩部成对但不完全镜像，尖端向主区串联 | 肩宽、凹口深、收尖长度；保持正常朝向 |
| 叶形 | 尖端、叶腹、基部收束 | 主脊 + 左右侧区；叶尖不塞不可点的小头 | 左/右倾、长宽变化、主脊偏移 |
| 双翼 | 两翼、窄腰、左右视觉平衡 | 双区各有局部链，并有一条跨腰依赖 | 翼宽、上下翼比、腰位置；腰不能被切断 |
| 双湾流线 | 连续反曲、两处开湾、整体单一重心 | 长路径沿大走势，短体作转接；不用原竞品大蛇外形描摹 | 曲率、上下比例、开口深度 |
| 环形 | 外缘与内洞形成一个整体 | 外圈与内圈节奏不同，内出口必须醒目 | 厚环/偏心环；洞数量初期固定 1 |

字母、节庆物件和复杂具象图形推迟到上述六类稳定之后。不能靠增加 silhouette 标签掩盖基本形体没做好。

### 3.3 几何约束（SHAPE）

| ID | 制作与验收要求 |
| --- | --- |
| SHAPE-01 | 普通形状的可玩格四邻接连通分量必须为 1；分岛关属于新增规则，不混入现有家族。 |
| SHAPE-02 | 非环形默认无封闭内洞；允许洞时必须记录并显示其出口性质。不能把随机缺格当“装饰”。 |
| SHAPE-03 | 普通连接颈宽至少 2 个逻辑格；承载相位旋转的关口还须检查两相位足迹，而非只满足颈宽。尖端可收至 1 格，但该格不安排唯一小热区。 |
| SHAPE-04 | 连续底板从 mask 联集生成；可做不超过 0.2 格的视觉圆角，不能改变逻辑通路。默认隐藏独立格砖边框，辅助网格只在教学/设置/选中时弱显示。 |
| SHAPE-05 | 轮廓内占用率按 mask 计算；同时记录两相位的轮廓识别图、内部空洞、屏幕像素管宽与间隙。不能只报 `fillRate`。 |
| SHAPE-06 | 原型先试 12～16 格的简单剪影，16～24 格的复杂剪影；这是待验证的制作分辨率。现核心允许边长最多 12，现内容最多 8，扩容前不得宣称支持复杂密盘。不要直接把所有关卡放大。 |
| SHAPE-07 | 首屏适配轮廓四周留出约 0.6～1.0 格观察带；允许出口动画短暂越界，禁止主体被底部操作区裁切。横长形采用横向舞台，不强行压入相同方框。 |
| SHAPE-08 | 96px 黑白缩略图做不带名称的形状分类；正式内测 12 人中至少 10 人能在 3 秒内分对家族，作为内部返工门。未测写 `UNKNOWN`。 |

**变换纪律：**整盘旋转必须同时变换 mask、身体有序格、头朝向和出口。镜像会把顺时针变成逆时针，而现规则固定为头部顺时针 90°：镜像后的两相位不自动等价，必须重新生成与验算。对心形等具象形状还要限制朝向。换色、整盘旋转、ID 重排不计独立谜题；镜像也不得未经逻辑去重就计新增。

### 3.4 内部路径编排（PATH）

- 单体始终尾→头有序、四邻接连续、无自交；各相位内部无重叠、无出 mask。可弯不等于可跨层，初版不画真假立交桥。
- 路径中心线用圆角曲线；转弯中心线半径先取 0.45～0.5 格，管身直径先取 0.64～0.72 格。邻近路径的可见间隙目标 0.18～0.28 格，以最终渲染测量为准。
- 中后期每盘至少有长/中/短三档路径。初始候选按长度分位分组，不用颜色区分长度；长体承担主走势，中体构成阻挡链，短体做钥匙或换气，禁止全盘只有 3～4 根超长体。
- 密盘先试长/中/短主体数约 25%/45%/30%，允许为逻辑改动。每个形状做“主带沿轮廓”和“主带横切内区”两种编排，评审后选择；不是给随机生成器一个概率就算完成。
- 局部同向平行直段连续超过 4 条须人工复核，避免机械条纹；禁止用格子碎屑填充率，单格主体只用于明确教学。
- 空白区应有用途：出口观察带、主体之间的呼吸缝或形状特征。每个无用途的内部大空洞须解释或重排。

### 3.5 批量复用但不假装有新内容

内容生成顺序固定为：**选择体验意图 → 作者剪影 → 拓扑检查 → 依赖结构草图 → 主/辅路径装配 → 两相位验算 → 解与反例 → 渲染检查 → 人工分级**。

每关保存 `shapeFamily`、`compositionId`、`rulesetVersion`、种子、解证书、难度维度、变换来源与原创来源。按几何旋转指纹去重，再按两相位阻挡关系图检查逻辑同构候选；后者未实现前不得写“全部逻辑独立”。皮肤、旋转、重新编号只记变体数。

发布批次采用“教学 → 新形体 → 两关练习 → 组合挑战 → 舒缓释放 → 主题展示”的七关节奏作为首轮候选。连续最多两关同外轮廓；不连续推出两个新规则。具体关号与比例由试玩校准，不保留“第 39 关起自动算困难”的旧做法。

## 4. 难度规范：从查找到决策

### 4.1 必须分别报告的维度

| 维度 | 定义 / 测量方式 | 不得替代它的指标 |
| --- | --- | --- |
| 查找负担 `searchLoad` | 主体数、转弯数、头方向分布、像素间距、追踪路径长度；真人首个正确动作时间 | 不能直接等于深度。 |
| 依赖层数 `dependencyLayers` | 每相位有向阻挡图；逐轮同时删除当前可出体，记录闭包波次、跨相位交替波次 | BFS 遍历状态数不能当人类思考层数。 |
| 相位价值 `phaseValue` | 不切相位是否可解、最少切换、每次切换实际解锁哪些体、是否只是空切换 | “蓝体数量多”不代表相位有价值。 |
| 有后果的选择 `consequentialChoices` | 同一可达局面至少两个合法动作：后继在可解性或有意义的资源最优值上不同；附完整反例与后续证书 | 初始可点击数量、被挡数量均不算。 |
| 前瞻跨度 `causalHorizon` | 作者明确列出“动作→改变条件→影响后续对象”的因果链，并用 solver 复核；真人能否解释再单列 | 强制单一路径很长不等于需要前瞻。 |
| 容错 `recoveryCost` | 失败后撤销次数、重做动作数、是否能在当前画面看到原因 | 罚生命或强制重开不是难度贡献。 |
| 操作负担 `inputCost` | 点击次数、命中失败、必须缩放次数、输入等待 | 越高越差，不作为升级理由。 |

对于现有单调规则，`consequentialChoices` 在“失去可解性”口径下恒为 0；当前报告已经验证这批数据。挑战模式若宣称策略深度，必须先改变这一点。

### 4.2 双模式与一项机制验证

**舒缓线**保留现规则。内容靠造型、路径追踪、逐层释放与相位变化提供乐趣，明确定位为观察解谜，不伪造危险。

**策略线**先做一个 HYPOTHESIS：**继电出口**，不同时加入钥匙、冰、颜色锁、传送门等多种机关。

- 普通边界继续按“遇到第一格虚空即离场”。仅有清晰标记的有向出口边可有开/关闸门；内洞若有门也必须标出。
- 带继电标记的主体移除后，翻转指定出口门一次。该关联始终可见；按下该主体时预览对应门的下一状态。普通主体不触发门。
- 门关闭使原来可出的主体被挡，因此移除不再只会改善局面。相位仍是 0↔1，蓝体旋转、固定体不动；不额外添加第三相位。
- 出口门使用边坐标与朝向定义，而不是凭视觉位置猜测；头部出射线命中该第一条边时检查门状态。
- 无生命扣减；永久开放撤销。无解时指出是哪条门依赖被切断，不能只弹“失败”。

**最小反例（抽象结构，不是已完成的关卡）：**A 是只能从门 G 离开的固定体；R 是可自由离开的继电体；G 初始开。先 A 后 R 可清空；先 R 会关 G，A 被困，相位也不能救回。需要撤销 R。作者必须把这个结构做成合法几何关，提交两条真实回放，再谈扩大内容。

机制原型只做 4 关：门状态教学、继电因果教学、上述顺序反例、与相位组合的两步预判。至少出现 2 个不同的非交换动作对；“换门的位置但同一个反例”只计一个。若 12 人小样中超过 3 人在教学后仍说不清联动，先改表达与教学；仍无改善则撤掉该机制，不靠加文案硬撑。该门槛是内部试制决策，不是统计学验证。

**不合格的加难方式：**缩小点击目标、低对比度、随机混色、插入更多格子、用提示次数卡关、盲目增加生命惩罚、限制相位次数却仍不产生有后果的主体选择。相位预算可作为优化挑战，但须如实标明它考的是切换效率。

### 4.3 难度带（V1 待真人校准）

| 带 | 作者意图 | 候选规模与结构 | 准入证据 |
| --- | --- | --- | --- |
| D0 教学 | 看懂一个因果 | 3～5 主体，一个新概念；无遮挡的主要点击点 | 新玩家无口头指导完成，解释正确。 |

## 5. 观感规范：统一材料，建立三种层次

### 5.1 视觉方向

采用“柔和瓷面舞台 + 半哑光软管”的原创方向。保留圆润、连续、可触感的品类语言；不复制竞品头型、配色排布、角色或具体剪影。

**远看**读轮廓与主色块；**中看**读内部路径与头朝向；**近看**才读高光、眼睛与选中反馈。装饰永远不得盖过这三个任务。

| 层 | 约束 |
| --- | --- |
| 背景 | 暖白 `#F6F3EB`，低对比；不放持续漂浮粒子。 |
| 剪影舞台 | 瓷白 `#E8E9DF`，一体轮廓；轻微接触阴影；默认不画每格卡片。 |
| 主体接地 | 单一右下接触影，偏移约 0.04～0.07 格，柔化约 0.06～0.10 格；随离场衰减。 |
| 管身 | 主色 + 下缘暗部 + 小面积上缘亮部；顶左统一光源；直段与弯段亮度连续。 |
| 头部 | 与管身连续的圆钝楔形，头宽约 1.05～1.15 倍管宽；箭向靠轮廓和鼻尖，不用突出的大三角。 |
| 眼睛 / 语义 | 眼睛随朝向，细节不超过头部宽度 45%；转动标记、固定标记优先于夸张表情。 |
| 瞬态反馈 | 选中体轮廓 + 局部路径；最上层只用于反馈，不给全盘所有体同时发光。 |

以上几何与颜色为首轮统一 token，须在真实尺寸检查后冻结；不能每个关卡自行调一套参数。

### 5.2 两类主体的恒定语义（VIS）

| 类别 | 颜色候选 | 非颜色线索 | 运动 |
| --- | --- | --- | --- |
| 可旋转蓝体 | 主色 `#4289C7`，暗部 `#285D91`，亮部 `#99CCEC`；只允许同一蓝青家族内小幅变化 | 头后短环 / 弧箭标记；教学和图例持续可查 | 相位时整体绕头切换 90°。 |
| 固定金体 | 主色 `#DFA94B`，暗部 `#9A6B27`，亮部 `#F6D895` | 头后双短条 / 固定扣标记 | 相位时保持位置与朝向。 |
| 继电体（待验证） | 保持其蓝/金基础类别 | 额外小继电符号 + 到门的按需关联线，不新增一套全色语法 | 移除时显示门切换的因果。 |

区分相邻同类主体主要靠接触阴影、留缝与按下描边。若同色长路径实测难追踪，先加同类内明度档和弱纹理，再决定是否扩色；不能退回完全随机彩虹色。红色仅用于受阻提示，绿色仅用于明确成功路径，不能充当固定体随机皮肤。

### 5.3 构图和 UI（LAYOUT）

- 顶部只放返回/菜单、关卡与剩余状态、一个次级入口。计时与误点默认在结果页，挑战模式可显示；不放无标签的小数字。
- 棋盘是主视觉。相位是唯一常驻强调命令，旁边仅撤销与提示；重开、上一关、下一关、设置、全出口导览进入合理上下文。通关后下一关才成为主命令。
- 相位按钮要显示当前“蓝体 0° / 90°”及切换后的方向预览，不用一个旋转箭头含糊表示持续同向转。
- 缩放使用一个有标签的紧凑入口，放大后显示复位。移除 `- / 100% / + / ⤢ / ◎` 长期占一整排的工具展示。
- 360×800、390×844、412×915：棋盘完整可见，常用操作在首屏内、不会被安全区压住。320×568：保留完整基本流程，优先折叠次级项，不让主操作掉到不可见处。844×390 横屏：棋盘与操作侧栏布局。
- 桌面舞台控制最大宽度但不铺满屏幕；不能把手机控件简单拉成长条。字体采用固定字号档，不用 viewport 字号。常规控件命中区至少 44px，主按钮优先 48px。
- 禁止用多层卡片、粗边框与巨量空白表达“高级”。输出黑白图检查层次，检查色觉差异模拟与键盘焦点；结果只作为辅助证据，仍需真人操作。

## 6. 点击、运动、声音与触觉规范

### 6.1 输入状态机（INPUT）

`idle → pressed → release commit / gesture cancel → accepted or blocked → settled`。每一步都有可见结果。

- 按下即确认“你碰的是哪根”：描边/亮度变化，不提前移除；松开一次提交。指针拖动超过 8 CSS px、第二指进入、`pointercancel` 或页面失焦则取消该次点击。8px 是待设备校准阈值。
- 不使用 DOM 绘制顺序抢热区。先判头部，再判实际身体距离；仅在空隙中扩展，邻体距离相近时显示选中预览而不是猜。头尖及眼睛区域必须属于同一主体热区。
- 密盘无法给每根不重叠的 44px 区域时，如实记录最小有效尺寸；提供放大、指向预览与键盘选择。不得写“所有箭头都 44px”却依靠重叠覆盖。
- 缩放是视图操作；不改棋盘状态、不增加误点。捏合结束后的手指抬起不能触发移除；一次键盘/指针动作不能同时移除与切相位。
- 合法移除在确认时提交一次逻辑状态，动画作为表现层；下一根的点击按新状态判定，不能等 360ms 动画结束才开放全盘。离场中的同一主体不可重复提交。
- 相位空间变换可短暂锁住棋盘，最长目标 300ms；期间触碰仍有“切换中”的即时确认，不暗中排队执行旧朝向的点击。已按下的旧状态手势在切换时取消。
- 撤销、重开、切关对动画使用统一取消协议。先恢复权威状态，再清理表现对象；不能出现已计分但又留在棋盘上的幽灵主体。

### 6.2 反馈时间表（FEEL）

时间从输入事件 / 状态提交点计，用帧录像与浏览器埋点记录。下列为 V1 目标区间，须实测，不声称当前已做到。

| 事件 | 目标时间与动作 | 验收重点 |
| --- | --- | --- |
| 触碰确认 | 首帧反馈 P95 ≤50ms；按下过渡 60～90ms；管宽最多增加 2% | 反馈开始时间与动画总时长分开测；无布局跳动。 |
| 合法移除 | 确认后立即起动，按沿路径的路程选 240～620ms；短预压缩 ≤35ms，可省略 | 头领路、尾跟随；可连续点不同体，不全盘等待。 |
| 受阻 | 沿实际朝向微推 0.06～0.10 格后回位，总计 140～200ms；仅最近阻挡点亮 350～500ms | 不用全盘红闪或左右无方向抖动；不改变状态。 |
| 相位 0→1 / 1→0 | 220～300ms；分别 +90° / −90°，以头部为轴；固定体不动 | 显示真实插值，不先换图再加一个无作用的 CSS transition。 |
| 撤销 | 120～180ms 还原方向/主体，减少运动模式直接还原 | 状态、计分、门状态、历史与界面同步。 |
| 通关 | 最后动作确认后及时给出成功信号；约 250～450ms 内展示可继续的结果层 | 计时当场冻结；不等长庆祝；下一关可操作。 |

### 6.3 滑出必须符合身体路径

实现参考：把初始尾到头中心线定义为弧长路径 `P[0,L]`，再沿头朝向延伸到第一个出口边界后。时间推进距离 `s(t)`，可见身体取路径窗口 `[s(t), L+s(t)]`，在出口平面之后约 0.6 格内裁去。尾端顺着原路径收回，头沿直出射线离开；不能把整根弯管作为刚体平移穿过邻体。

圆角采用连续弧长采样，头朝向取路径切线；末端收束不突然切断。内洞是现规则中的出口：进入洞后在该出口裁去，不横穿洞再从另一侧“重新出现”。出界判断仍由核心提供，渲染器不得另写一套判定。

相位旋转是投影变化，不是普通实体在地板上扫过。两端姿态必须合法，旋转期间可用轻微抬升和变化中的接触影表达处于不同平面；**中间扫掠不参与碰撞**。必须给出 0/25/50/75/100% 帧检验，避免看上去撞穿金体却没有解释。若此表达仍被误解，应改为明确相位投影转场，而非假装实现了物理碰撞。

### 6.4 声音与触觉

- 成功移除用短促、柔和的释放声；随长度只轻微变化，连续连点作限幅与声部限制，不叠成刺耳噪声。
- 受阻用短哑音；相位用双音说明两态变化；通关用独立短句。不要每个事件都播同一个正弦哔声，也不要让音量随“困难”变大。
- 触觉是补充通道：成功轻触、受阻短双触、相位轻双触；参数先在支持设备试 6～12ms 单触和间隔约 25ms 的双触。浏览器/设备不支持时安静降级，不宣称有震感。
- 声音与触觉分别可关；首次声音遵守用户激活限制。减少运动模式关闭位移、抖动与粒子，保留按压描边、状态图和文本/图形确认。

### 7.2 对标与内测方法

固定 12 人内部试制样本（新手/同类熟悉玩家各 6），先不介绍设计目的。A/B 左右位置与体验顺序各半，展示设备与宽度一致。必须同时保留旧版，确认新版到底改善了什么。该规模用于发现明显问题，**不等于商业偏好或统计上的非劣效证明**。

- **静态**：六个形状做 96px 识别；三组棋盘问“更清楚 / 更有整体感 / 更精致”，把三个问题分开。内部停止线：每项至少 8/12 认为新版达到或优于所展示参考；未达则返工，保留原始票数。
- **语义**：不靠口头解释，至少 10/12 能在 5 秒内区分可旋转与固定体；单独记录色觉差异与读图困难，不用总体票数掩盖。
- **输入**：真实尺寸累计至少 200 次有记录的目标选择；区分“点错对象”“点到对象但判断错通路”“手势被误识别”。前者目标 ≤2%，全部错误保留录像/事件时间；不以脚本命中率代替手指表现。
- **逻辑**：D0/D1 先测理解，D3 测能否说出门依赖和为何要先移除某体；求解器、作者与玩家的解释逐项对照。记录首个正确动作时间、完成时间、撤销、提示和放弃；先收集分布，再校准关卡带，不伪造最佳时长。
- **手感**：按下响应 P95、误识别、相位动作解释、连点接受情况、滑出连续性分别记录。可用“响应及时/动作自然/结果明确”1～5 分辅助，但无帧证据时不报毫秒结论。
- **边界**：如果只有宣传截图，对标结论只能写“静态构图/材质达标与否”；竞品震动、声音、真实难度等一律 `UNKNOWN`。不安排未经授权的外部招募或消息发送。
