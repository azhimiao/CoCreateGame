# 05｜下一批游戏与平台匹配：不要把 3–5 款乘以平台数量

这是**试验路线图**，不是已经做好的游戏、确认采购需求或成功率排名。平台热度来源与证据局限见此前完整研究包的渠道矩阵与原始来源。

## 后续三款具体优先级（须等待第一款数据）

### 游戏二：Signal Warehouse｜信号仓库

- 从 Vector Shift 复用：纯函数状态、棋盘渲染、格子阻挡、提示、Undo 和求解器。
- 新规则：玩家只能改变一条轨道方向，机器人携带物品遵循线路自动运输。
- 和第一款相比：基于空间路径而非移除顺序；可复用但不是仅替换贴图。
- 停止条件：若复用并未缩短新游戏实际总工时（含人工调试/关卡审核），暂停扩张通用机制层。

### 游戏三：Sort Line｜分拣线

- 核心：移动传送带和颜色箱子，限定空置缓存数，按订单归位。
- 面向更广泛的手机休闲用户，但市场高度同质化，需要真实素材点击/试玩测试确认差异。
- 只有获得正面留存与发行准入信号后，再加长期成长/广告和移动移植。

### 游戏四（候补）：Pendulum Run｜摆荡竞速

- 目标测试第二个游戏底层家族：连续物理、移动手感和误差容忍。
- 若前两款 Grid 系作品获得重复授权线索，优先把机制库变成收入，而不是转向不相关技术栈。

## 不能混淆的四类证据

1. **热门榜**：证明有玩家正在接触某个类型，不证明你的游戏也有流量。
2. **准入规则**：证明平台允许审核，不证明获得推荐。
3. **官方采购声明**：证明可能提供授权合同，不证明对你开出现金报价。
4. **收入到账**：只有真实合同与支付记录才是商业回报证据。

首批测试需分别记录：候选创造成本、完整可玩成本、平台适配成本、QA与人工策划时间、发行状态、自然流量/推广流量、商业许可收入。最后按**组合累计贡献利润**而不是上架量决定下一轮。
