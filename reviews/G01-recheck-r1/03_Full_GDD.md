# G01 完整 GDD：信号港

版本1.0.0，审计修订audit-r1；全部自有机制、数值和内容为 **HYPOTHESIS**。20关数据见 `game-spec.json`。此为施工定义，未开发、未真人验证；Hypatia首审REVISE，当前修订待独立复核，ready=false。

## 核心规则与精确定义

棋盘宽高4—7格，原点左上，x向右、y向下。箭条是有序、不重复、正交相邻的格集合，按尾→头排列；最后一段决定N/E/S/W方向；单格箭条方向取显式字段。所有初始箭条、墙、门格互不重叠，门打开也不能允许初始重叠。

玩家触发 `EXIT(id)` 时，箭条**整体刚性平移**，不沿自身折线蛇行。令方向向量d，初始格集合C，完整出界期间扫掠为 `S = union((C+k*d) intersect Board), k=1..max(width,height)`。只要S与其他尚在场箭条、墙、关闭的门任一格相交，本次非法；同一箭条自己的初始格不构成障碍。全部净空才一次性移除，没有中途停留、推挤或绕路。弯条尾部同样会被阻挡，不能只检查头部射线。边界没有隐藏出口，朝向决定退出哪条边，该边任意位置可出。

检查优先级：不存在/已移除 → 船期方向不符 → 箭条碰撞 → 墙 → 关闭门。多障碍返回同类别最近扫掠步数k、再按(y,x)、再按对象ID排序的第一个用于高亮；规则合法性不依赖此UI排序。

固定提交合同：提交前完整扫掠校验 → 移除箭条 → 翻转其 `toggles` 中每个门一次 → 非空船期游标+1 → 先胜利再死锁评估 → 保存新逻辑状态 → 播动画。门切换用提交前状态验证通路，所以箭条不能靠“自己离开后打开门”救自己。纯规则只返回RuleFacts；SessionCoordinator唯一合并首通集合、分配eventId并将不可变快照排入串行保存队列，然后动画呈现。失败写盘保持内存已提交态并提示，不伪称保存成功；中断/回执不再提交或重复保存。完整字段、同局面不同历史及胜利撤销再完成合同见04及contracts/session-vectors.json。

## 四种可分离版本

| 版本 | 规则开关 | 独立决策差异 | 消融方式 |
|---|---|---|---|
| BASE | 无门、无船期 | 找空间依赖次序 | 对照版 |
| RELAY | 仅信号门 | 有g/h印记的箭条离港后翻门；提前清除可能关闭他人的路 | 移除门及toggles即回基础，不改变碰撞系统 |
| MANIFEST | 仅船期 | 下一次出港方向必须等于船期首项；同向箭条要规划选哪一个 | 清空manifest即回基础，不依赖门 |
| COMBINED | 两者均开 | 同时满足航道和班次，切换时机产生未来依赖 | 作为组合测例，不以“更复杂”推定更好玩 |

门g以琥珀色+圆符号显示，门h以青色+方符号显示。关闭是实心带横闩，打开是虚线框，箭条尾部有对应符号；颜色不是唯一信息。开关不会自动恢复、不会随时间变化。`toggles=[]` 则无副作用；可同时翻两个门，但字段不能重复。

船期是长度等于箭条数的方向数组；空数组禁用。只允许当前首项方向的箭条出港，错误方向不移动、不扣费。整条船期可查看，当前项加亮；没有通配、跳过或购买改期。游标由已接受操作数导出。

## 成功、失败与恢复

胜利：所有箭条离开且船期已消费完。空船期的游标恒0。非法点击只给短反馈，不减少生命、不增加计步、不扣任何资源。死锁：仍有箭条且无任何合法EXIT，立即进入可关闭的死锁面板，提供撤销和重来。存在合法但未来无解的状态不自动宣告失败；玩家继续操作后可能死锁，提示也可识别“当前无可通关路线”。

撤销免费且无限：从接受日志移除最后一次EXIT，重算箭条、门和船期；没有重做。胜利页可撤销最后一步回局内，但已获得的首次完成印章不撤回。重来需确认，清空当前局日志、保持已完成集合与设置，关卡回初始状态。未操作时撤销禁用。退出/刷新不重开，恢复最后一次已提交逻辑状态。载入失败不随机填棋盘。

提示不修改局面：从可通关的合法后继中按箭条ID字典序选第一条，描边并显示“这条可安全离港”；当前无通关路径则显示“当前路线无法完成，请撤销或重来”。同局可重复，无遮广告、次数、币。求解状态最多2^8=256，实际性能待测。

## 完整玩家路径

| 节点 | 输入与状态 | 反馈/文案 | 验收目标与异常 |
|---|---|---|---|
| 加载 | BOOT读内容、校验存档 | 进度条“准备航道” | 不虚报可操作；失败转ERROR，3秒未好给重试提示（假设） |
| 首入 | 点HOME“开始”进L01 | “沿箭头方向离港，先看整条航道” | 可操作引导目标3—10秒，尚未测；不强制动画等待 |
| 首次行为 | 点击a，校验并提交 | 航道描边、箭条平移、轻响 | 反馈目标≤100ms，错误显示阻挡格，不扣费 |
| 第一胜 | L01清空 | “航道已清空”，印章1/20 | 下一关/重玩/地图；保存失败提示不会重复奖励 |
| 错误/第一败 | 非法点击或L08等死锁 | “航道受阻” / “没有可离港箭条” | 非法不算败；死锁可撤销/重来，禁广告救援 |
| 复玩 | 地图点已完成关或重来 | 初态、已有印章标志 | 不追加印章；重来确认不影响历史完成 |
| 新机制 | L05、L11首次进 | 门印记或船期图例 | 只说明一次规则、不自动替玩家出手；HELP随时复看 |
| 中期 | L08/L13先后顺序 | 全部门状态/船期可预读 | 不增加未知障碍；L13同方向选择可死锁 |
| 成长 | 按顺序完成20关 | 地图20节点、印章计数 | 无数值战力；首通才开下一关 |
| 退出/回归 | PAUSE回首页，或系统后台 | 已提交状态即存档 | 无时间流逝惩罚；音频恢复需用户手势 |
| 全通 | L20首次胜利后下一步 | COMPLETE“20条航道全部完成” | 仅地图/重玩；不伪装有后续关或日常活动 |

首通只给一个印章，计数=完成关卡ID集合大小，20上限。不定义星级/最短步奖励：成功解的移除数天然等于箭条数，不能假造“最短步深度”。难度用分支选择、几何依赖和可达死锁探索，目标时间只是待测假设。

## 输入与产品边界

触屏/鼠标：在同一箭条按下并抬起，位移≤10 CSS px才提交；移出、pointercancel、第二指触碰均取消本次。无长按动作、缩放、拖棋盘或双击功能。点箭条任一格等价。键盘Tab按ID聚焦箭条，Enter/Space提交；U撤销，H提示，R打开重来确认，Escape暂停/退上层。弹窗独占输入；动画期间丢弃棋盘输入而不排队，支持暂停/静音。

背景为空格不做动作。错误不震屏；减弱动态模式将平移改为80ms淡出，门状态立即切换。当前20关无随机生成；seed仅作内容来源标识。所有后续关卡、变体扩展、广告与经济需改版审查，不由施工Agent自行增加。
