# 游戏项目目录

CoCreateGame 管理多款独立游戏。每个游戏文件夹保存自己的设计档案、源代码、美术音频、测试和项目配置。G01—G10 是 Foundry 准备轨道里的稳定编号；`VectorShift/` 是独立获准施工的既有游戏，不占用新 G 编号。跨游戏研究放在仓库根目录的 `research/`，独立审计放在 `reviews/`。
