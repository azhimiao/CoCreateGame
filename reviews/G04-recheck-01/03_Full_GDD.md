# 完整 GDD｜折光机关

规格1.0.0；所有游戏设计为 **HYPOTHESIS**。B0 是唯一主版本；X1/X2 是独立机制实验。机器内容为 `game-spec.json`，本文与04为语义约束。

## 一句话与核心循环

在两张相互影响的机关板间护送一枚光标：观察两层和目标位型 → 选择一步移动/同位升降 → 踩入开关翻转共享机关位 → 重新规划道路 → 在有限步数内以指定机关位抵达出口。没有箭头消除、匹配三消、随机掉落或刷涂覆盖。

世界观为抽象精密光学工作台；章节只用机关图示和关名表达，不设角色对白、剧情分支或角色版权需求。胜利恢复一台小型折光装置，视觉演出不改变数值。

## 坐标、实体与可通行性

坐标 `[layer,x,y]`，layer=0下层、1上层；原点左上，x向右、y向下。每关宽高各3—5，两层相同尺寸。`.`为基础地面，`#`为固定空缺；光标占1格，无朝向、惯性、连续碰撞或重力。最多3个共享位 A/B/C，整数 bits 的低位为 A；每位取0或1，不是颜色混合。

门叠加在基础地面上，只有 `((bits >> bit)&1)==value` 才存在支撑/允许进入。一个格最多一扇门，只控制一个位；可与开关、升降台、出口重叠。互补门是位相同而value相反的一对门，可在不同层；不是上层美术遮住下层的不可见障碍。两层所有门状态都公开可看，层切换预览不改变 bits。

开关格定义 XOR 掩码1—7；进入一次翻转一次，多位掩码原子翻转。`bits ^= mask`，没有保持按压、自动回弹或永久一次性开关。离开开关不触发；再次进入会再触发；初始化站位不触发，关卡禁止在起点叠开关。仅按键选中/长按/暂停不触发。每格最多一个开关。

升降台列表是 `[x,y]`，两层该坐标都必须为基础地面。命令 X 在台上跳到另一层同位；需目的格当前可通行，不是任意瞬移。进入另一层的格也会触发该格开关/信标。门可以临时使升降目的层不可用；无效 X 不扣步。

## 输入合同

U/R/D/L 每次只移动正交相邻一格，X 升降；均消耗1有效步。方向键/WASD和触屏方向盘相同；Space/屏幕“升降”发X，Z/撤销发UNDO，R键保留给向右的内部命令但键盘重开用独立按钮和 Escape 后菜单，避免 R 与 WASD 混淆：键盘 **D=R，R字母无绑定**。触棋盘正交邻格可发一步，其余格只查看详情；不提供滑动连走。切换观察层只是 VIEW_LAYER，不是X。触控/输入细节见06。

## 严格结算次序

每个命令只在 PLAYING 接受。先验证几何/升降台与**旧 bits**下目的格支撑；无效输入完全不变，含步数、pending、history与提示状态。有效动作按以下次序执行，不能在动画回调里改次序：

1. 保存完整动作前快照，提交新坐标，used加1。
2. XOR应用旧pending并清零；B0/X1的pending恒为0。若新位置失去地面，立即 FAILED/FLOOR_CLOSED，后续开关不触发。
3. 读取目的格开关；B0/X1立刻翻bits，X2仅将mask写入pending。
4. 再检查脚下地面，若关闭立即 FAILED/FLOOR_CLOSED。关闭旧位置、远处门或另一层门不伤害当前棋子。
5. 仅X1处理目的格信标顺序，错误时 FAILED/BEACON_ORDER。
6. 仍在PLAYING时，位置等于出口、bits精确等于目标、pending=0且信标全部完成，置 WON。
7. 仍未胜/败且 used>=move_limit 时 FAILED/MOVE_LIMIT。最后一步达目标判胜；前面坠落/顺序失败优先于目标。

无链式开关：门开闭不触发开关，门下或开关旁的棋子不自动触发。没有WAIT命令，UI等待、无效输入与切后台不推进延迟。到出口但位型不对仍可继续走；用“出口未校准”提示，不能虚判胜或自动失败。可达性陷入死路不自动判断输，撤销与重开始终可用。

## 成败、提示、撤销与成长

MOVE_LIMIT、FLOOR_CLOSED、BEACON_ORDER 为全部关内失败类型；加载/SDK/存储错误不是玩家失败。失败页保留最后局面与具体原因，可立即撤销或重开，无生命、复活费、广告门槛。撤销恢复位置/bits/pending/信标进度/used/PLAYING与失败原因，弹出一条有效动作前快照；无历史则无操作。最多128条，关卡预算≤128；**WON不可撤销**，可选“重玩”新开一局。

提示免费且不自动走步：从当前状态在剩余预算内 BFS 求路，只高亮一条下一命令；无解则提示“试着撤销或重开”，不提供错误路线。按下确认提示前将本局 assisted=true，撤销不能恢复false；重开重置本局assisted。BFS内部运行不是平台统计。没有隐藏收集物、货币、背包、日常任务或限时活动。

L01默认解锁，首次胜利解锁下一关，L20胜利后回地图显示全通；可重玩所有已解锁关，未通关不能跳过。三星：未用提示且used≤par；二星used≤par+2，其他预算内一星。用提示且达par仍为二星。undo_count只作本地QA可选字段，不影响星数；撤销会恢复used，因此星数代表最终提交路线而非总尝试。重复胜利只取更高星与更低best_used，不重复给任何货币。20关后无伪无限内容。

## 两个可分离实验

X1 仅添加有序信标列表。进入当前 next_beacon 索引对应格则进度+1；已完成信标可重复踩且不变化；提前进入未来信标立即失败。每格最多一个信标，起点无信标；出口可重叠但先判信标。移除信标列表并切B0即可得到同几何对照。

X2 仅改变开关时序：进入只排队pending；下一次**合法**移动落位后、触发新格开关前生效。该移动预检仍用旧bits，因此不能以“它马上开”为由跨过当前关闭的门。新格被旧pending关闭会失败，未触发新开关。pending仅存一个掩码，每次合法动作先清旧后排新；无累积时钟。出口上的pending不为0不能胜。切B0则改回立即触发，其他结构不变。两实验在12分别测试，不混用两项。
