## P02 CrazyGames

E05 FAQ https://docs.crazygames.com/faq/ 明示内容不符PEGI-12、面向儿童、缺英文、克隆等可能被拒。产品定位一般16+策略解谜，不是低龄识色；内容是否合规由平台审查，不伪称已分级。Basic为有限玩家测试，Full须再满足要求和审查；没有保底推荐、晋级或收入。

E06技术页 https://docs.crazygames.com/requirements/technical/ ：

- **总资源≤250MB、≤1500文件**；初始下载≤50MB，移动首页资格≤20MB。
- 无SDK Basic：以**全包**作初始下载，因此全包≤50MB，移动首页资格全包≤20MB；不能套250MB逃避更严约束。
- 有SDK：初始下载从加载到首个真正可操作状态的gameplay start，菜单不算；Full **必须**SDK，按官方规定上报start/stop等。
- Basic **禁变现**，不集成广告/IAP入口。V1所有包均无广告；将来若考虑Full广告需重新设计并审批，不能从Basic收入估ROI。

测量方法见07，游戏包体/文件数/首屏速度当前UNKNOWN，不能用准备档案ZIP替代。Basic与Full产物分别锁profile和SDK；不得把Basic上传成功当Full集成验收或现金流。

P03不在G04候选，但若公司将来协商任何Web排他协议，须先检查是否阻断P01非独家与P02发行。P04也不在G04候选；若未来获批适配，E07 https://wiki.playgama.com/playgama/game-requirements/technical-requirements 禁GA4等第三方统计，限定平台Bridge内置统计或本地离线QA。不得因为已有事件系统就让第三方统计进入所有包。

P05/P06未列本游戏候选，不承诺网页游戏直接成为合格移动发行包。若未来改用其发行，APK/SDK/买量/权利须重新立项审查；本轮不联系、不扩范围。其他游戏/平台的CPI、留存、授权价不移用来估G04回报。

## 必审合同字段与具体风险

| 字段 | G04必须核清 | 未知/停止条件 |
|---|---|---|
| copyright_owner | 自有规则实现/原创关卡/美术音频与外包权利链 | 任一关键资产权属不明不交付 |
| licensed_scope / territory / platforms / term | 网站/域名/地区/移动/Web容器、期限、版本更新 | “全平台永久”不得默认接受 |
| exclusivity / sublicense | 是否排他、渠道排除、转授权对象和范围 | 冲突P01/P02则停止并行承诺 |
| source_code_delivery / derivative_works | 是否交TS、数据、编辑资源；改作与续作归谁 | 卖游戏不自动卖整个生产库 |
| engine_reservation | 通用规则、验证工具、流程与非专有组件保留 | 要求全部底座IP时转专项人类决定 |
| rev_share_base / ad_spend_recoupment | 毛收入还是扣税/平台费后，退款/坏账/UA谁承担 | 分母与回收顺序未明确不算收益 |
| audit_rights / reporting | 每月曝光/启动/广告展示/归因/净回款、对账和审计 | 只有总网络规模无单游戏数据为UNKNOWN |
| payments / currency / taxes | 金额、币种、税费、门槛、发票、结算周期、逾期处理 | 报价不是收款，到账前不写已验证 |
| minimum_promotion | 是否有明确曝光/测试预算/创意支持 | “可能推广”不当保底 |
| termination / delisting / successors | 下架时效、存量许可、违约救济、转让主体/被收购后义务 | 无退出/无限修改责任需停审 |
| privacy / SDK / AI assets | 数据角色、SDK许可、原创/生成资产申明与赔偿上限 | 无法合法履行即拒绝该方案 |

这些是审查字段和商业决策门，不是已获得的合同条款。报价、谈判、是否接受买断或排他均由人类另行决定。必要第三方许可与P01无URL界面规范的具体处理要书面确认，不能删许可强行过审。

## 收益模型与证据口径

净贡献 `N = 实际净许可到账 + 实际净分成到账 - 人力 - AI工具 - 原创资产 - 测试设备/招募 - 法务 - 维护 - 可归因投放`。预算/日成本、许可金额、平台分成比例、RPM、流量、净回款均UNKNOWN，不填行业猜值。盈亏平衡许可净额=所有成本减其他实际净收入；若是分成，需先取得有效每启动净收入才可算启动量，缺分母不计算。

收入台账需合同号、授权范围、发票、银行到账、币种税费、账期、开发者实际收到净额。主页展示是关注线索，作品目录是经验，准入规则是可进入性，只有交易/到账支持商业化。重复授权至少两份相容且有净回款的许可才初步支持，不因两个投稿入口存在就称规模化。
