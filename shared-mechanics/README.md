# 共用机制提案区

本轮只定义复用边界，不建设通用游戏引擎。

P0可共同使用的候选：整数网格坐标、不可变状态快照、显式命令/事件、撤销栈、带版本存档、seed、输入回放、关卡见证序列、JSON Schema、平台适配端口。每款自己的合法动作、胜负/机关语义仍在各自施工档案，不以同名概念假设二进制兼容。

未来提案必须附：稳定接口、状态序列化、边界/错误码、许可证、维护所有人、依赖版本、跨项目回归向量和两位审查记录。接口通过审查才合并，禁止多个作者覆盖共享源码。

不共享：商业对标的关卡/代码/素材、某平台SDK的全局状态、移动发行商私有归因、未审查的玩家数据；不强行把G01箭头规则变成G04机关规则。跨引擎只共享中立JSON/数学定义/测试向量，不假设TS直接运行C#。

本目录没有运行时实现；研究脚本不构成已完成的制造引擎。底层工具与单款IP权利边界见 `../research/contracts-and-rights.md`。
