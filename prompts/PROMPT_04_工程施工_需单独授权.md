# PROMPT 04｜仅在用户选定 Gxx 且审核通过后执行

本 Prompt **现在不得自动执行**。

输入：经用户批准、已通过独立审计的 `games/{GAME_ID}/` 施工档案。

目标：交付完整可玩的 Release Candidate，而非仅能跑通的原型。

严格按 GDD 制作，不重写玩法；按系统依赖顺序推进，实装每一个菜单、教程、关卡/经济/存档、操作、美术、动画、音效、错误分支。必须有可复现测试、真机/真实浏览器检查、录屏截图和一份逐项需求对照验收。

分离「游戏逻辑」「引擎渲染」「平台 SDK」「数据统计」「品牌素材」。共享机制库在合并前需要独立测试/许可审查，不允许 Gxx 在不同 Agent 之间相互覆盖。

交付完整项目、源码、锁定依赖、构建脚本、各目标平台技术候选包、QA 报告、版权资产清单、剩余缺陷、真实制作成本和复用指标。

不擅自签第三方合同、不擅自向平台正式提交、不产生未经授权的付费调用。不得宣称通过未实际进行的人工试玩和第三方审核。
