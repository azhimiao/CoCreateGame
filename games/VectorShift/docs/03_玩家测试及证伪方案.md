# 03｜玩家实验与可证伪性：先证明有人愿意玩，再制作更多游戏

## 核心假设

| ID | 假设 | 具体否证方式 | 下一步动作 |
|---|---|---|---|
| H1 | 玩家看完开局后可以理解箭头离场规则 | 10 名未看说明的玩家有 4 名以上无法在60秒内过第1关 | 重写教程并重新测试 |
| H2 | 相位规则可以在不依赖解释的情况下学会 | 10 名玩家中 4 名以上在第3关无法独立发现相位按钮，或超过90秒仍无法理解 | 调整机制呈现、按钮反馈或教程 |
| H3 | 20关难度呈现合理的渐进变化 | 第5关完成率急剧下降，或玩家普遍觉得关卡“随机、不讲理” | 重排关卡、换筛选评分；不能只增加提示 |
| H4 | 玩家愿意继续玩下一关 | 第3关后自愿继续到第5关的比例很低 | 排查玩法本身和关卡节奏，而不只改画面 |
| H5 | 相位机制相较纯箭头移除增加乐趣 | 在随机分组试玩中，相位版理解成本增高但主动继续率无改善 | 停止优先研发相位机制，转其他差异机制 |
| H6 | 自动生成关卡节约人工策划成本 | 人工修复、重排和试玩时间超过直接制作成本 | 改进生成与评价系统；暂停产能扩张 |
| H7 | 非独家授权有真实付费买家 | 联系10个当前有效渠道，均无法获得明确评审意愿或报价线索 | 不预估靠授权快速回本，转分发或其他品类 |
| H8 | 有发行商实际给这类作品分配流量 | 正式提交后始终无法进入有效测试流量池，或没有可解释拒绝原因 | 不继续为此渠道开发定制版 |

**以上判断线是本项目实验前的止损假设，不是来自行业的标准 KPI 或统计显著阈值。** 10人样本只用于发现严重可用性问题，不用于预测留存或付费率。

## 第一次测试：10 名未经讲解的新玩家

实验者只给试玩链接，不提前讲解相位机制。玩家允许独立阅读界面规则，不能由研究者告诉他们点哪里。

- 第1分钟：记录首次成功离场耗时、首次不合法点击、是否理解被挡原因。
- 第3关：记录是否自行发现相位按钮、首次成功切换后是否知道蓝色箭头已经改变方向。
- 第5关：记录是否愿意继续，询问失败理由和最有趣的时刻。
- 结束后问：你会推荐给谁？愿不愿意明天回来？如果只能改一件事，是什么？
- 记录设备、屏幕尺寸、是否戴耳机、是否卡顿、是否看懂文案，不记录敏感个人信息。

实际指标定义：

1. `L1自主完成率 = 完成第一关 / 进入第一关的有效试玩者`。
2. `L3相位发现率 = 未经研究者提示使用相位通过第三关 / 进入第三关的有效试玩者`。
3. `L5继续率 = 自愿开始第五关 / 完成第三关的有效试玩者`。
4. `关卡阻塞事件率 = blocked_click / arrow_removed`，用于定位规则认知问题而非评价水平高低。
5. `人工关卡审查成本 = 审查人分钟 / 可保留关卡数`。

数据来源：客户端通过**本机**记录匿名事件，点击“导出试玩记录”会下载 JSON，用户可以主动选择交付给研究人员；不会自动发送。请向参与者说明记录内容与保存方式。Coolmath 候选构建关闭此能力。

## 第二次测试：约 100 名实际玩家（预算允许后）

用不同来源的玩家随机分配为 A/B 两组：

- A：原始静态箭头清除（单独制作对照版），保持同等视觉与教程质量。
- B：现在的相位箭头版本。

基准版本 A 尚未作为成品实现。正式实验前应先固定分流、埋点定义和平台规则；不能把不同平台的玩家直接当作随机对照。

预先规定成功/失败的主要指标（如 L5 继续率、3关完成率、单次游玩时长），不要在看到结果后再挑看起来好看的指标宣布成功。因100人样本仍偏小，差异需附不确定性范围。

## 避免错误推断

- `BFS exploredStates` 是机器搜索空间，不是玩家难度；玩家难度需要实测完成时间、提示量、失败原因。
- 通过“20关可解”不能推出“有趣”，也不能推出留存和收入。
- 玩家说喜欢不等于愿意付费；平台上架不等于平台主动推荐。
- 公开热门榜中的成功作品属于幸存样本，不能用它们预测一个新作品的 ROI。
