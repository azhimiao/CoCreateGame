# 证据与验证口径

本轮访问日期：2026-10-21（Asia/Shanghai）；该日期不是来源发布日期。冻结范围为P01—P06和G01—G10。原包总纲/JSON为输入基线；本次观察另存，便于复核。

## 可复核链

`official-sources.json → claims.json → platforms/Pxx.md → games/Gxx/01_Market_Evidence.md`。游戏具体页面和操作分析另见 `benchmarks/`。每条重要事实应落到具体URL，不能只引平台首页。`source-access-log.json` 保存本机HTTP访问时间、状态码、最终URL、标题、响应长度和SHA256；它是访问证据，不证明网页正文语义正确，更不证明实际试玩。网页内容另由本次web阅读核对，不将搜索引擎抓取日当本次访问日。

本地保存元数据、自写摘要及带操作日志的研究截图。浏览器正常加载会产生第三方运行缓存；临时profile排除在交付包之外，截图仅作研究证据，没有将对标专有代码、美术、音频或关卡导入自有产品及可复用素材库。链接发生重定向或HTTP失败时保留原始错误；独立web读取与本机HTTP结果可能不同，不能删错美化。

## 标签

| 标签 | 允许支持的结论 | 不能支持 |
|---|---|---|
| OFFICIAL_DOCUMENT | 当前公开准入和流程描述 | 本团队已获批或协议完整内容 |
| OFFICIAL_GAME_DESCRIPTION | 作品存在、公开控制和规则 | 已实玩、隐藏数值或留存 |
| HISTORICAL_PORTFOLIO | 曾展示/发行该作品 | 2026新作采购偏好 |
| DIRECT_OBSERVATION | 带设备、操作和时间记录的本次实际现象 | 大样本体验或全关卡结论 |
| SECONDARY_RECONSTRUCTION | 据官方教学/说明重建的一条可能操作路径 | 真实30秒/5分钟录像 |
| HYPOTHESIS | 我方原创规则、关卡、预算和验证门槛 | 官方产品真实数值或行业平均 |
| UNKNOWN | 未观察、未公开、未测试 | 0、没有、不会发生 |

公开评分、目录位置、安装区间、公司累计下载等分别记录量纲及时间窗口。安装区间不是独立活跃用户，目录存在不是热榜，热榜不是购买意向；本次不据此推算成功概率。

## 深度分析边界

优先尝试真实浏览器访问并保留截图/错误；凡没有完成操作的项目必须用间接分析标签。官方说明不足以确认广告出现时间、第一关布局、首五分钟关数、货币或后期参数时，逐项UNKNOWN。允许写原创候选的预期30秒/5分钟路径，但必须与对标实际轨迹分开。本轮后补的Paint Master胜/败/重试局部证据及跨批次边界见 [实际操作汇总](observation-summary.md)，不能把驻留时间当连续有效游玩。

## 独立审计与验收

P0作者只写各自目录；另一位Agent只凭施工档案复述规则并出具GO/REVISE/KILL。主控对明确规则歧义和数据错误修复，再由独立审计复核。所有尚未解决的BLOCKER阻止READY_FOR_BUILD。关卡数据验解只证明指定规则下可达目标，不证明好玩、原创性通过或渠道采纳。

本轮可执行脚本仅用于证据重核、schema/任务依赖校验、关卡规格验解和交付打包，不是最终游戏源码，也未运行PROMPT_04。

## 重现

在仓库根目录执行 `python tools/validate_preparation.py`（离线）重查结构、schema、依赖及本地关卡验证。在线重核执行 `python tools/recheck_sources.py`。依赖见 `requirements-research.txt`；本轮不声明安装过Cocos/移动SDK，不声称运行过真机或真人盲测。
