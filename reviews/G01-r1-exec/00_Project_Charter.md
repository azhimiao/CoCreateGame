# G01 项目章程：信号港 / Signal Harbor

版本1.0.0，audit-r1；准备日期2026-10-21；状态 **REVISION_REQUIRED，修订待独立复核**。`ready_for_build=false`，尚无开发或提交批准；全项目ZIP由主控统一生成。

## 产品与玩家

G01 属于箭头路径消除家族。工作名“信号港”：玩家像港口调度员一样，先确认整条箭形船的航道，再选择离港顺序；信号船离开会改变航道门，船期单约束下一次出港方向。叙事只作为信息组织，不引入角色剧情、战斗或资源经营。

目标玩家为 **16 岁以上**、愿意在桌面或手机花数分钟做空间排序题的玩家（HYPOTHESIS）。P02 内容需符合官方 PEGI-12 要求，但“PEGI-12 内容边界”不是把游戏面向儿童的依据；本项目不采用幼儿教育定位、儿童角色、儿童定向营销。成人偏好和可读性均未真人验证。证据 E07。

需求假设：基础箭头清场容易解释；“清除一个对象会关闭另一条路”的可逆决策，有机会让玩家在小棋盘上感到规划而非机械点击。两者均是 HYPOTHESIS，不宣称已证明好玩或市场原创性。预注册反证见 12。

## 明确范围

首批产品定义为 20 个固定原创关卡，BASE / RELAY / MANIFEST / COMBINED 四种规则组合；点击、触屏、键盘等价输入；英/简中文；无限免费撤销、重试、解题提示；完成印章与本地进度恢复。没有体力、金币、商店、日历奖励、联网排行榜、UGC、每日随机题、内购或强制广告。免费提示是本项目设计，不是对标参数。

所有棋盘、动画时间、颜色、玩家试验样本、预算与停止阈值均 **HYPOTHESIS**。日期、ID、官方技术限制、实跑离线计数是可核查事实，不与设计参数混为一谈。当前仅允许编写用于数据验证和打包的 Python 脚本，无最终游戏源码、Cocos 场景或可玩 HTML。
