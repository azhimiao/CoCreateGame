## 必须写进构建验收的硬条件

P02：[technical](https://docs.crazygames.com/requirements/technical/)官方总≤250MB、≤1500文件；初始下载≤50MB，移动首页≤20MB；无SDK Basic用总包作为初始大小。项目Basic采取总≤20MB的保守预算，**Basic禁变现，Full SDK必须**。不得用SDK提前发送Gameplay start掩盖菜单后加载。[FAQ](https://docs.crazygames.com/faq/)排除儿童定向内容。以上是准入约束，不是实际构建结果。

P04：[technical](https://wiki.playgama.com/playgama/game-requirements/technical-requirements)要求Bridge，**不得嵌GA4等第三方统计**；仅Bridge/本地离线QA。root index.html、拉丁文件名、≤300MB archive、无外部登录依赖、无域名锁、旋转保存与声明的系统兼容都必须真实检验。Bridge支持多门户不代表可以混入P02SDK或绕过另家投稿。

P01预留：[submit](https://www.coolmathgames.com/submit-a-game)禁广告（含自家推广）、外链、开发者回传统计和名字输入；许可信息离线显示。它可能购买非独家许可，但是否购买G01、金额/范围/周期均UNKNOWN，不在本轮自动新增候选。P03排他若主控另议，先冻结冲突的Web投稿，不默许与P04并行。

## 版本与数据隔离

构建标识分别为LOCAL_QA、P02_BASIC、P02_FULL、P04、P05、P01_RESERVED，存档key/SDK/事件出口独立。游戏内容可共享关卡数据和原创资产，SDK不共包；商业协议需写清各平台、地区、期限、分发站点，不以技术profile替代合同许可。

本地QA可在测试者同意后离线导出匿名轨迹；正式P04只平台SDK统计、P01不回传、Basic不自建采集。用户拒绝统计不影响离线解题；涉及平台同意流程按该平台当前合约与隐私规范另验。不得跨站关联身份或拿P02测试样本推P04成功率。

## 合同逐字段决策表

| 必审字段 | G01底线 / 停止条件 |
|---|---|
| copyright_owner / derivative_works | 原创关卡/资产权属清楚；游戏专有权利与通用工具分开；无法明确则不签 |
| licensed_scope / platforms / territory / term | 按Web/原生、具体平台地区期限列举；“全媒体永久全部内容”须重新估值与人类批准 |
| exclusivity / sublicense / successors | 排他冲突先解决；转授权渠道清单、继受义务明确；禁止默增独家范围 |
| source_code_delivery / engine_reservation | 是否交游戏源项目明示；通用制造层/其他Gxx不在交付，必要运行许可单列；索要整套工厂资产则停止 |
| rev_share_base / ad_spend_recoupment | 总/净收入、税费/渠道费/坏账、汇率、UA回收次序、负债上限逐项写明；未知不填平台平均值 |
| audit_rights / payments | 按渠道原始数据可导出，结算周期、币种、最低支付、争议处理；不可核查净款则不进入商业验证 |
| minimum_promotion / milestones | 有无保底曝光、谁承担预算、修改次数与验收；没有承诺不能写“保证推广” |
| termination / delisting | 退出、下架和尾款时间；素材/账户/数据回收边界；无合理退出且无限维护义务则停止 |

当前所有具体合作合同字段为UNKNOWN；表是谈判需求不是已达成条款。网页营销支持/流量覆盖不能替代书面预算、排他正文或实际付款证据。不得发邮件/消息问价，准备问题清单留待用户批准对外沟通。

## 成本、收入与ROI口径

本项目提议的探索上限（全部HYPOTHESIS、未获预算批准）：开发+QA+资产+研究总计不超过80个折算人时；货币总成本上限人民币12,000元含人时估值、素材/工具、测试、法务、维护与失败成本。80小时与12,000元是双约束，不重复相加，不代表已发生支出或承诺报价。达到任一上限前先决策，不用自动追加投入维持目标。

成本台账每条记录日期、项目、类别、实际现金、折算人时及估值、是否失败返工。收入只有银行/渠道结算实际净回款才记；应收报价单独列，不并入利润。`G01贡献利润=实际净授权款+实际净分成回款−全部G01成本`。组合ROI须由主控把其他失败游戏纳入，G01不能以自身结果代表全部组合。

没有真实RPM/CPI/留存/报价，故当前ROI=UNKNOWN，不给伪收益预测。若未来有已审计的每千次有效启动净回款r、累计成本C、固定净许可款L，盈亏平衡启动数为`max(0,(C−L)*1000/r)`，仅r>0且同渠道同窗口可用；现在r、L均UNKNOWN，不能代入猜测行业均值。没有保底时按零保底决策。

## 商业停止与回退

1. 未取得相容权利、要求转让通用制造资产、无限成本回收/修改义务或看不到真实数据：停止该合同，不签后再补。
2. P05不支持Cocos且切引擎超预算：停移动分支、保留已审Web档案，不宣称原生可交付。
3. P04最低系统兼容无法满足且无正式例外：停止P04提交，不以现代设备流畅掩盖不合规。
4. 有效同渠道测试两轮仍未通过自己的体验门槛/平台审查，且无可证改进方向：暂停该渠道投资并复审G01，不改名当新产品重复投。
5. 触及成本上限、未获得可归因真实曝光或实际净款不足覆盖后续维护：停止增量内容；保存规则/关卡/工具资产，禁止为交付数量扩做同质版本。

技术通过、获得投稿入口、Basic上线、分销报告、签约和净回款是不同里程碑。当前只完成准备档案与离线数据验证。
