# 七个非P0候选结构抽检

2026-10-21。范围仅G03/G05/G06/G07/G08/G09/G10的章程、03规则研究问题、12证伪表与结构声明抽检；不是完整GDD或独立GO审计。没有要求本轮补齐其玩法/20关/工程实现。

七份03均明确`SPEC_NOT_COMPLETE / RESEARCH_SKELETON / ready_for_build=false`，不是把13文件齐全当Ready。虽复用同样章节和研究方法，关键问题、两变体对照、反证及许可风险有家族实质差异：

| 项目 | 抽检到的具体内容 | 应保持的边界 |
|---|---|---|
| G03 | 库存预留与功能修复分开测；两单取舍、误交、断供/软锁；无广告前30分钟经济闭环 | 资源/订单经济未定，不搬对标数值，不当完整经营GDD |
| G05 | 因果回读/安全预演，区分误触与不可见信息；控制tick、碰撞、死亡重置待定 | 不是泛写“更公平”；未知控制与原创关卡阻止施工 |
| G06 | 固定点改变重心与路线支路分离；成功/翻覆/货物脱落/超时优先级待定 | seed不保证物理跨设备一致，不默认自研刚体或换车皮就原创 |
| G07 | 优先级调度与缓冲分配分开；需求序列、瓶颈、阻塞及离线资源守恒 | 自动化后仍需有后果的选择，不用只增长金币冒充经营 |
| G08 | 信心决策和真实群体差异分开，匹配误拒/误接纳有各自分母 | 样本来源/转授权未定，AI不得伪造民调排名；不默认真人实时对手 |
| G09 | 隔板双舱与一次暂存分开；合成原子提交、重复配对、越界终局 | 固定seed不等于浮点一致；不借皮肤数量掩盖空间策略未定 |
| G10 | 可逆叠层与主题约束分开；遮罩返工、锚点、可接受作品及导出权 | 角色/衣物/用户导出许可与成本未核，理论组合数不是表达价值 |
