# 每屏UI、触控与音画资产施工规格

以下为 **HYPOTHESIS** 规格，不是已完成素材或视觉验收。视觉方向是成年通用解谜的精密纸板/磨砂玻璃工作台，禁幼儿教具、卡通儿童角色、廉价发光边框堆叠。无角色、商品装扮或第三方商标。原作只参考“状态清晰”，不复制画面、图标和具体关卡。

## 响应式坐标与触控

采用逻辑CSS像素，安全内容矩形 S=可见viewport减safe-area四边，不能把安全边距缩放两次。默认参考390×844，边距16、间隙8；文字正文16、说明14、标题24、数字18，最小14。按钮最小48×48，文字按钮高48；主按钮宽不小于144，焦点框2。点击在pointerup且移动距离≤12px、同一目标内才成立；移出/取消/双指次指不触发。动画锁内移动丢弃、不暗排队；按键忽略repeat，一个keydown只走一步，keyup重置。

断点只执行一个分支：先将安全区域宽限制为1200并居中（高度不缩放）；记W/H。先判W/H≥1.3进入LANDSCAPE，否则W≥700进入WIDE，否则PORTRAIT。LANDSCAPE和WIDE共用侧栏几何。**不再以W<700抢先判竖屏，不因棋盘太小跳回另一分支。** 几何不满足下述最小值则U11“窗口太小”，保留Session，提供首页/重试；旋转后重新计算。

PORTRAIT：四边16；工具条48；目标/位型条80（内含72×72缩略图，上下各4，文本区在左）；底部输入区176；三个区间各8，共24。棋盘边长 `min(W-32,H-360,420)`，小于160则窗口太小。默认390×844得到358；320×568得到208，每格41.6，因此方向盘是可靠主输入。底部176内，上108为两排方向：上排U、下排L/D/R，按钮52×52、行列间4；独立X升降96×52在上排右侧（方向组164宽+8+96=268≤320-32）；下方8间隔与撤销/提示/重开48高，余12留白。工具按钮可等分可用宽，最小48，不自动增为第三行挤占棋盘。

LANDSCAPE/WIDE：四边16；侧栏宽W<800时224，否则240；板区与侧栏间16；板区可用宽C=W-32-侧栏宽-16。板区上方48工具条，再间8；板可用高D=H-88。若min(C,D)<160或H-32<316，进入窗口太小。若min((C-16)/2,D)≥160则两层并排、间16；否则单主棋盘边长min(C,D,420)，另一层72×72缩略图置于侧栏80高目标区内。侧栏依次目标80、间8、方向108、间8、升降52、间8、操作48、余4；合计316。600×400只会LANDSCAPE，C328/D312，单板312；844×390为LANDSCAPE，C556/D302，双板各270；768×1024为WIDE，双板各240。禁止拉伸棋盘。

所有分支每格边长board/max(width,height)，格边≥48才允许邻格点击移动，否则格点只查看；方向/X按钮始终满足上述尺寸。缩略图点击仅切观察，不升降。当前棋子所在层有实线边框与“你在下层/上层”；观察另一层显示虚线“查看上层，光标仍在下层”，方向输入仍控制光标真实层。validate_contracts.py仅核算这些尺寸与唯一分支；最终字体/截断/触控必须后续真机渲染验收。

邻格点只从真实棋子当前层发移动；预览另一层时格点只inspect，方向盘继续移动后自动回真实层。空格/其他非邻格选中高亮并展示门/开关规则，绝不自动寻路。键盘方向/WASD移动，Space升降，Z撤销，Esc暂停；Tab可循环UI，Enter激活焦点按钮，不将Enter当移动。非文本输入场景阻止页面滚动/选中，保持站外浏览器导航可用。

所有覆盖层有显式关闭与返回焦点，禁止无法关闭的模态。弹窗打开时棋盘命令不接收；失败/胜利/帮助不得共享底层点击。旋转屏幕保留Session，重新布局后重绘，不能重复触发开关。教程在L01指开关/目标、L03指升降、L05指互补门；不把停留时间作为强制通行条件。

## 视觉编码与层级

底色#121A24，板面#243343，正文#F4F6F8，次字#BCC8D2，边界#66788B。A=琥珀#F2B544+三角，B=青#48D7CB+圆，C=紫#BC9BFF+方。0=空心+数字0，1=实心+数字1；门中写A0/A1等，不能只靠色彩。当前光标为白色菱形黑描边；出口为双边框圆环，中心写所需层。空缺为明确叉纹，关闭门为条纹面，开启门为带标签边框；避免透明误认地面。

绘制层从底到顶：背景0、板影10、基础格20、门30、升降/开关40、信标50、目标60、光标70、选择/受影响线路80、HUD100、覆盖层200。多个实体同格按此层级组合，开关小徽章占右下角，门标签左上、信标序号右上、出口环不盖光标；关闭门仍显示其下开关图标，规则详情解释风险。

当前位型与目标位型并排显示A/B/C，位数以本关为准；未匹配位有描边并文字“尚需B=0”。剩余步≤3用文字强调，不闪烁催促。X2 pending在位型下独立小条：“下一次合法移动后：A翻转”；不能把未来位型伪装成当前已开门。所有教程/失败原因有EN对应：Calibration complete / Floor closed / Beacon order / Move limit reached / Undo / Lift / Inspect upper layer。

## 动效与音效触发

有效移动140ms ease-out、升降180ms层交叉淡入；开关80ms压下+门120ms明暗转换、受影响线路只闪1次。逻辑先完成且输入锁≤180ms。无效动作60ms局部2px偏移+原因字幕，不抖全屏。失败180ms收暗，胜利600ms精密环展开，350ms即可显示可按按钮；没有长不可跳动画。减动效时移动/升降/门≤50ms，无粒子/抖动/闪线；终态相同。

音频仅用户手势后解锁：移动短click、开关双tone、升降短sweep、拒绝轻tick、失败低tone、胜利三音。每类100ms去重、同时声源≤4，主峰≤-3dBFS；音效默认开、音乐默认关。若开启背景音乐，唯一60秒可无缝循环轻环境音，无旋律侵权借用。后台/暂停停止，iOS中断返回在继续手势恢复；无音频仍能完整解题，声音从不承载唯一规则信息。
