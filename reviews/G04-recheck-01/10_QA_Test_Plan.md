# QA计划、已执行证据与未执行项

质量分为规格逻辑、运行实现、用户体验、平台/商业四类。前一类通过不代表后者通过。所有拟定体验/性能阈值为HYPOTHESIS。

## 本轮实际运行

`python -B validate_spec.py`：Python和jsonschema版本、UTC生成时点、输入SHA-256见 `validation-report.json`。检查Draft2020-12 Schema本身及两份数据，20正式关+2实验夹具的每步合法性/终态与BFS最短长度，固定golden21条，任务DAG无环和依赖存在，以及4条Schema负例。每关trace公开初态到WON，不是游戏视频。

| 固定向量 | 意义 | 预期 |
|---|---|---|
| Q01/Q18 | 越边/空缺 | BLOCKED，状态和used不变 |
| Q02 | 非台X | NO_LIFT，不变 |
| Q03 | 离开再进入同开关 | XOR再次翻位，非保持开关 |
| Q04 | 最后允许步到目标 | GOAL优先于耗步失败 |
| Q05/Q06 | 抵出口但位型错 | 可继续；预算耗尽才MOVE_LIMIT |
| Q07 | 新格开关关闭自己脚下门 | FLOOR_CLOSED，used已增加 |
| Q08/Q09 | 失败后撤销/重开 | 恢复完整初态与PLAYING |
| Q10/Q11 | 提前信标/已完成信标 | 错序失败；已完成信标幂等 |
| Q12/Q13 | 延迟生效/无效输入不走拍 | 下一合法移动应用pending；碰墙不应用 |
| Q14 | pending在落点关闭脚下 | 失败且不再触发后续机关 |
| Q15 | X落在另一层开关 | 正常进入触发 |
| Q16 | WON后的移动与撤销 | 均拒绝，不改变状态；UNDO_LOCKED |
| Q17 | 旧bits下关闭门预检 | BLOCKED，不允许透支未来开门 |
| Q19/Q20 | 空撤销/撤销待生效开关 | 安全no-op / pending也回滚 |
| Q21 | 目标位置+位型正确但pending未空 | 不能胜利 |

`qa-vectors.json` 的预期状态和原因是明示固定值，未用step临时生成expected；用于后续独立TS实现交叉验证。Python额外JSON round-trip只证明这些数组可序列化，**没有实现或验证产品双槽存档、云端、浏览器存储或游戏回放UI**。

Schema负例：未知TELEPORT动作、门value=2、任务缺depends_on、伪造DONE状态均必须拒绝。关联约束如越界地面、同类重复机关、mask超位、DAG环由脚本断言；未来需扩展故障注入覆盖，不能声称当前负例穷尽所有错误。运行失败必须非零退出，旧report不能当新成功，要比较input_sha256。

## 获批施工后必须新增的实现测试

1. 纯规则对照：TS跑全部golden、每关trace逐字段相等；随机合法状态枚举验证支撑条件/幂等拒绝/undo互逆。初始位、开关与门重叠、升降台门控、双位mask、目标和开关重叠各自单独固定断言。
2. Session：WON锁撤销、FAILED能撤销、assisted不可撤销洗掉、重开重置本局辅助但保留完成、连续胜利回调只结算一次。帧率/动画时长变化不改trace。
3. 任务/内容：缺ID、未知variant、尺寸不一、起点闭门、目标闭门、无解、解超预算、par错误全部阻止内容进入产品；从同一版本输出确定性hash。
4. 求解器：从当前态而非初态给提示；含pending/信标键；余步不足返回NO_PATH；无解/超时可退出、不卡主线程、无自动移动。
5. 存档：双槽一槽损坏/指针错/写中断/两槽损坏/QuotaExceeded/SecurityError/未知版本/内容hash更新；恢复前重放并对终态，伪造history拒绝；两次导入幂等。
6. 生命周期：visibility hide/系统音频中断/SDK pause重叠时只停一次；全部原因解除且用户继续才恢复；不重复开关/完成事件。WebGL lost重绘后状态相同。

## 屏幕、输入和音画QA

U00—U12逐屏截图及屏幕进入/退出测试。尺寸320×568、390×844、768×1024、844×390、1366×768；notch/底部安全区、浏览器地址栏变化、横竖切换、长英文与中文缺字、放大文字、键盘Tab顺序/焦点恢复、减动效/静音。指标：不裁剪/重叠，所有主要触控≥48，窄棋盘邻格移动自动关闭且方向盘可用。

双指、按下移出、拖动>12px、pointercancel、锁内连点、keydown repeat、UNDO打断动画、提示覆盖层点击穿透、预览另一层时点格，全部录制输入与最终状态。连续100次重开/切层/进出设置不堆音源、不涨事件监听；实际内存曲线记录，不声称无泄漏仅因代码审查。

色觉模拟和实际截图测对比度；门0/1、A/B/C、当前/目标/预览层不用纯颜色区分。音频手势解锁、静音后不漏声、手机来电回前台、音乐开关记忆；音频失败时仍能独立理解所有规则。

## 浏览器/真机与平台证据

按07矩阵逐设备填型号、系统/浏览器版本、RAM、实际构建hash、网络条件、HAR和错误日志。Android/iPhone/4GB Chromebook缺一项就标UNKNOWN，不能用桌面窗口缩放推定真机。测试首可玩时点、帧时p95/卡顿、内存、方向输入延迟与首包，不把准备ZIP大小作引擎游戏包。

P01：解包静态搜索网络/广告/URL并动态HAR验证，必须无开发者统计/外链/广告/姓名输入；必要许可文本单列审查。P02 Basic无SDK按全包50/20MB判；有SDK首次真实可玩发start；Full必须SDK。总250MB/1500文件硬检查，Basic广告/IAP入口都无。所有正式包禁独立第三方统计；P04未来获批适配只Bridge或离线QA，不准GA4。

SDK网络离线/超时/重复回调/嵌入不同origin、存档禁用都要验证。平台实际审核通过、投放和开发者回款当前全部UNKNOWN，不用“本地通过”代签平台。

## 玩家盲测与缺陷门槛

按12预登记协议，招募一般16+解谜玩家，提供标准中/英文版本，不先讲规则；记录首动作、错误预览、前三关理解、提示/撤销、退出理由。研究仅人工观察或local-qa离线导出，需自愿同意，去身份，禁止在P01产品偷回传。没有真人记录时所有体验结论维持UNKNOWN。

BLOCKER：无解/规则歧义、存档毁坏且无恢复、触控无法继续、SDK或平台硬要求违反；修复后必须回归。MAJOR：错提示/错星、层误认、关键字缺失、难度绕过教学、包体/真机不达目标；不能靠截图解释掉。MINOR：不妨碍理解的对齐/字距/音量细节。正式发行零BLOCKER，MAJOR需明确修复或书面接受；未签收不得把状态升READY_FOR_BUILD/RELEASE_READY。

当前未执行：Cocos/TS、浏览器、真机、网络性能、音画成品、玩家盲测、独立审计和发行审核。没有为这些项目生成虚假PASS。
